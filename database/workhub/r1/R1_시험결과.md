## 지문의 범위

"지문 동일"은 다음 범위에서만의 증거입니다. 이것을 "파일·계정이 모두 보존됐다"로 넓혀 읽으면 안 됩니다.

| 대상 | 지문이 보는 것 | 보지 않는 것 |
|---|---|---|
| `auth.users` | id 목록 | 이메일·비밀번호·세션·메타데이터 등 나머지 열 |
| 다른 버킷의 `storage.objects` | 버킷·경로·객체 ID·owner 4열 | **파일 본문 바이트**, metadata·version·시각 열 |
| `storage.buckets`(수합 버킷 제외) | 행 전체 | — |
| public 표 | 행 수·행 전체 해시 | — |
| R0 표 22개 | 행 수·행 전체 해시 | — |

파일 본문은 DB 밖 저장소라 SQL 로 볼 수 없습니다 → 실행안내 7번(기존 제출 파일 1개 내려받아 열기).
앱 대조에서 발견한 서버 결함은 없습니다(배부 파일 기대값 비교는 앱처럼 `collectionFiles` 로 정규화한 뒤 비교해야 함 — 시험 도구 쪽 수정).
