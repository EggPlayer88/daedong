# R1 제약 처분표 · 변경 명세

2026-10-15 · 요청서 PR #34 `docs/workhub/32` 7절(표·제약·통합 API 대응)에 대한 답입니다.
숫자는 시험 DB(PostgreSQL 17)에서 카탈로그로 센 값입니다(유일 = PK 제외 UNIQUE, 트리거 = 사용자 트리거).

## 2. 통합 계약 대응

| 통합 계약 | R1 표 |
|---|---|
| API-08 요청·게시 | `collections`, `collection_schemas`(게시 문항판), `collection_fields`, `collection_reviewers`, `collection_plan_units`·`collection_plan_unit_members`(게시 전 대상 명단), `collection_units`·`collection_unit_members`(게시 때 snapshot) |
| API-09 초안·제출 | `unit_drafts`, `unit_draft_files`, `submission_versions`, `submission_files` |
| API-10 검토·보완·정정 | `submission_reviews`, `correction_requests`(보완), `collection_correction_fulfillments`(보완 충족·철회 시 복구), `correction_windows`(마감 뒤 정정창), `submission_withdrawals` |
| API-17 파일 | `file_objects`, `file_access_grants`, `deletion_ledger`, typed 관계 `collection_file_intents`·`collection_template_files`·`unit_draft_files`·`submission_files` |
| 공통 정책·실행 | `policy_catalog`, `policy_versions`, R0 접수·감사·outbox·서비스 주체 |
| R1 실행 보조(신설) | `file_verification_jobs`, `file_verifier_heartbeats`, `api_role_principals`, `batch_installs`, `r1_switch`·`r1_switch_log`, `r1_secrets`, `r1_storage_policies` |

**배부 파일은 generic `file_links` 를 쓰지 않습니다.** `collection_template_files`(수합·요청판·파일·순서) 전용 관계를 두었고,
AI 양식 분석과 무관합니다. 업로드 예약의 부모·목적은 `collection_file_intents` 에 고정합니다(template | draft, 제출판은 부모가 될 수 없음).

**철회·정정은 JSON 덩어리가 아니라 행입니다.** 철회 = `submission_withdrawals`(제출판·행위자·사유·시각), 정정창 = `correction_windows`
(단위·기한·사유·허용 조작·승인 정책판).

## 5. Storage

| 대상 | 값 |
|---|---|
| 버킷 | `workhub-collection-files`, 비공개, `file_size_limit` 100MiB(열이 있을 때) |
| INSERT 정책 `workhub_collection_insert` | `authenticated`, 이 버킷 + `object_insertable(name)` |
| SELECT 정책 `workhub_collection_select` | `authenticated`, 이 버킷 + `object_readable(name)` |
| UPDATE·DELETE 정책 | 없음 → 교체·삭제 불가(시험 G13~G15). 물리 삭제는 작업자가 Storage API(서비스 키)로 |
| 요청 종류(`storage.operation`) | 두 판정 함수가 허용 목록으로 본다: 업로드는 `object.upload`, 읽기는 `object.get_authenticated`(업로드 요청 안의 되읽기는 `object.upload`). 서명 URL 발급(`sign`·`sign_many`·`sign_upload_url`)·목록·이동·복사·TUS·S3·값 없음은 거부(시험 G53~G61) |
