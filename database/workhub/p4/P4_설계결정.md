# P4 설계 결정

2026-10-16 · Claude Code. "판단해서 정한 것"과 그 이유, 되돌리려면 고칠 곳을 적습니다. 확정은 계란님입니다.
P2 의 공통 틀(`module_activations`, P2-80/81 중지·재개)과 R1 의 Storage 판정(`c_object_owner`·`c_storage_ok`)을 그대로 이어 씁니다.
기준 계약은 PR #48 의 앱 parser(`knowledge/*contracts.ts`, `documents/*contracts.ts`)와 서버 API(`_knowledge_import.py`, `_guided_service.py`)입니다.

## 1. 공통

## 4. 원문 가져오기(knowledge_import)

| 번호 | 정한 것 | 이유 | 되돌리려면 |
|---|---|---|---|
| D-P4-3 | 업로드 예약 → 본인 업로드(경로 `학교/소속/파일/original.hwpx`, 30분 안) → 서버 API 가 claim → 내려받아 추출 → finish | 앱 `import-adapter.ts` · 서버 `_knowledge_import.py` 의 순서 그대로 | P4-02 원문 부분 |
| D-P4-3a | claim 은 **처음 고정한 Storage 실물 id** 와 신고 크기·SHA 를 돌려주고, 실물이 바뀌었거나 크기가 다르면 `CONFLICT` | 올린 뒤 실물을 바꿔치기해도 다른 내용이 추출되지 않게(시험 F48·F49) | `p4_kclaim` |
| D-P4-3b | 임대 120초, 같은 파일 10분 6번·같은 계정 10분 60번 넘으면 `pending` 만 | 내려받기·파싱 반복으로 서버를 괴롭히지 못하게(시험 F51) | 〃 |
| D-P4-3c | 추출문은 파일당 1건으로 고정(고칠 수 없음). 다른 요청 번호로 다시 해도 같은 추출문 | 같은 파일에서 다른 본문이 나오면 근거가 흔들린다(시험 F29·F32) | `knowledge_extractions` 트리거 · `p4_kclaim` |
| D-P4-3d | 추출 SHA 는 서버 API 의 `json.dumps(sort_keys, 공백 없음, ensure_ascii=False)` 와 DB 표준형(`p2_canonical`)이 같은지 finish 때 비교 | 앱이 초안을 만들 때 보낸 `extractionSha256` 가 실제 추출문과 같은지 확인할 수 있게(시험 F25) | `p4_kfinish` |
| D-P4-3e | 원본 1개로 자료 초안 1개만(동시 2번이면 하나는 `CONFLICT`) | 같은 원문이 자료 여러 개로 갈라지지 않게(시험 F34, P4-03-10) | `knowledge_sources` 유일 조건 |

## 6. 질문형 양식(guided)

| 번호 | 정한 것 | 이유 | 되돌리려면 |
|---|---|---|---|
| D-P4-6 | 양식을 이을 수 있는 수합 = **내가 담당(owner)하는 게시된 수합 중 HWPX 파일 칸이 있는 것**. 수합 1건당 게시 양식 1개 | 수합 담당자가 그 수합의 제출 양식을 정한다. 같은 수합에 양식이 둘이면 교사가 어느 것을 써야 할지 모른다(시험 G04·G38) | `p4_tpl_target_ok` |
| D-P4-6a | 분석(inspect)·생성(render)은 서버 API 만(service_role claim/finish). 분석 결과는 원본 SHA 에 고정 | 양식 원본은 브라우저가 직접 읽지 않는다(시험 G10). 다른 원본으로 매핑을 바꿔치기하지 못하게 | P4-02 양식 부분 |
| D-P4-6b | 게시하려면 **현재 답변 판으로 만든 시험 생성 파일**이 있어야 함 | 칸 연결이 실제로 파일에 들어가는지 확인한 뒤에만 교사에게 내보낸다(시험 G35) | `p4_tpl_apply` publish |
| D-P4-6c | 게시판은 고칠 수 없음(`P4_TEMPLATE_IMMUTABLE`). 대상 교사는 수합 단위 배정(`collection_unit_members`)으로 정함 | 교사들이 답하는 동안 질문이 바뀌면 답변이 어긋난다 | 〃 |
| D-P4-6d | finish 전에 출력 실물이 Storage 에 있어야 하고, 생성 파일은 그 실물 id 에 고정. 실물이 바뀌면 내려받기 `CONFLICT` | "올렸다"는 주장만으로 확정하지 않는다(시험 G46·G49) | `p4_op_finish`·`p4_artifact_access` |
| D-P4-7 | **생성 파일은 만든 사람만** 내려받음(수합 담당자도 남의 생성 파일은 못 봄) | 제출은 수합 단계(R1)에서 교사가 직접 한다. 생성 파일은 제출 전 개인 초안이다 | `p4_artifact_access` |

## 8. 계란님이 정하실 것

1. **D-P4-1**: 학교 자료 게시·종료를 학교 관리자만 할지(지금), 교과 부장·업무 담당자에게도 줄지
2. **D-P4-7**: 생성 파일을 만든 사람만 볼지(지금), 수합 담당자도 볼지
3. 문서함 학교 공유 범위(`document_school_share`) — P4-04 입력
4. 원문 가져오기·양식의 파일 크기(`max_file_bytes`) — P4-05 입력
5. 자료·문서·생성 파일 보관 기간과 삭제 — 이번 계약에 없음(지금은 영구 보관)
