# T2 시간표 운영 SQL — 실행 안내 (계란님 SQL Editor)

> 비활성 설치다. 아래 1~3단계를 마쳐도 교사 화면에는 아무것도 바뀌지 않는다. 켜기 전에는 T2 조회 · 미리보기 · 실행이 모두 `NOT_READY` 이고,
> 예외는 셋뿐이다: 준비 상태 조회(readiness, `not_installed` 를 돌려줌), 자기 요청 번호의 복구 조회, 자기 요청 닫기(`_abandon`).
> 켜기 전에는 원장이 비어 있으므로 복구 조회는 `NOT_FOUND`, 닫기는 취소 기록만 남긴다(학교 자료는 바뀌지 않음).
> **켜기(T2-08)와 알림(T2-02)은 따로 승인**한다. 결과는 표를 그대로 복사해 알려 주세요.

## 0. 전제

- T1-07(2026-10-19.1) 설치와 T1-08 · T1-09 확인이 끝나 있어야 한다(T2-01 이 확인하고, 없으면 아무것도 만들지 않고 멈춘다).
- 이 PR(T2 SQL)은 **SQL 실행 → 병합** 순서. 병합해도 앱 배포에는 영향이 없다(SQL 파일과 시험만 들어 있음).

## 1. 사전 점검

`T2-07_통합사후점검.sql` 을 실행한다. 아직 T2 가 없으므로 T1-09 와 같은 판정이어야 한다.
- 정상: status 에 **FAIL 이 없음**(12 · 13 은 info).
- FAIL 이 있으면 멈추고 결과를 그대로 알려 주세요.

## 2. 설치(한 파일씩, 순서대로)

| 순서 | 파일 | 정상 결과 |
|---|---|---|
| 1 | `T2-01_운영_모델.sql` | T2-01-1~3 모두 ok |
| 2 | `T2-03_조회_공개.sql` | T2-03-1~4 모두 ok(3 = 아직 켜지 않음) |
| 3 | `T2-04_교환_요청.sql` | T2-04-1~3 모두 ok |
| 4 | `T2-05_학사변경.sql` | T2-05-1~2 모두 ok |
| 5 | `T2-06_실시기록.sql` | T2-06-1~3 모두 ok |

- 파일마다 한 트랜잭션이다. 중간에 오류가 나면 그 파일은 아무것도 남기지 않는다. 다음 파일로 넘어가지 말고 오류 문구를 알려 주세요.
- 이미 적용한 파일을 다시 실행하면 "이미 적용되었습니다"로 멈춘다(정상).

## 3. 사후 점검

`T2-07_통합사후점검.sql` 을 다시 실행한다. **FAIL 0** 이어야 한다.
- 이제부터는 T1-08 · T1-09 대신 T2-07 을 본다. T1-09 는 03 · 09 · 10 행이, T1-08 은 02 · 05 · 08 · 10 행이 FAIL 로 나온다(T2 표 · 함수 · 트리거를 모름 — 정상, 시험 A06).

## 4. 따로 승인 — 알림(T2-02)

교환 요청의 동의 · 승인 요청 · 결과를 알림함으로 보내려면 `T2-02_알림출처_시간표.sql` 을 실행한다(T2-02-1~2 ok).
그다음 T2-07 을 한 번 더 실행해 FAIL 0 을 확인한다. 실행하지 않으면 알림 없이 동작한다.

## 5. 따로 승인 — 켜기(T2-08)
