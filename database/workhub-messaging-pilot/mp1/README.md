# 일반 교사 한 명의 메신저 시험

2026-10-25 사용자 요청: 시험 회원은 `teacher`를 유지한다. 지정한 한 계정만 업무실의 메신저를 사용하며 실제 교사 연결·일반 공개는 보류한다. 운영 실행과 병합은 사용자가 한다.

## 달라지는 동작

서버 허용이 있는 시험 교사는 기존 평가계획서 메뉴에 더해 메신저 전용 업무실을 연다. 관리자용 전체 업무실·학교 설정·시간표·문서·AI 등은 열리지 않는다. 메뉴만 숨기지 않고 기존 `legacy_gate`, `member_actor`, P2 대상 판정도 그대로 유지한다. MP1은 메신저와 첨부의 기존 15개 함수에서만 별도 주체 검사를 사용한다.

새 테이블의 허용은 한 계정·한 학교·한 소속으로 제한한다. 승인된 `teacher`, 활성 계정·학교·본인 소속, 유효기간, 시험 허용 기간을 확인한다. API 역할에는 새 표 읽기/쓰기나 내부 함수 실행 권한이 없다. 설치 직후 허용은 0명이다.

첨부는 기존 HWPX 검사·파일 ID·객체 ID·참여자 검사를 유지한다. 최신 Storage의 인증된 다운로드 정보 조회(`object.get_authenticated_info`)도 같은 조건으로 처리한다. 서명 URL·공개 다운로드·목록 조회는 허용하지 않는다.

## 실행 순서

한 단계의 정상 결과를 확인하고 다음으로 간다. 설치와 시험 허용은 별개다. 이전에 안내한 **슈퍼관리자 부여 SQL은 실행하지 않는다.** 미실행 상태이므로 회수 SQL도 필요하지 않다.

## 사용자 시험

관리자 창의 기존 작성 중 메시지는 유지하고, 시험 계정은 별도 브라우저 프로필이나 시크릿 창에 로그인한다. 같은 브라우저의 일반 탭은 로그인 세션이 공유될 수 있다.

1. 관리자: 시험 교사를 수신자로 선택 → 내용·첨부·받는 사람 확인 → 전송.
2. 시험 교사: 메신저에서 수신 메시지 확인 → 읽음 처리 → HWPX 다운로드. 파일이 한글에서 열리는지, 원본과 일치하는지 확인.
3. 관리자: 상대 읽음 확인. 시험 교사가 HWPX를 첨부해 답장하고 관리자도 내려받는다.
4. 종료: `MP1-80_시험허용_중지.sql`에 시험 Auth UID·중지 사유를 넣어 실행. 계정 역할과 기존 메시지·첨부는 보존하며 시험 교사의 메신저 접근이 차단된다. MP1-02에서 active=0을 확인한다.

종료 시각은 현재부터 최대 7일이다. 만료는 별도 예약 작업 없이 매 요청과 화면 타이머에서 판정한다. 연장이 필요하면 같은 계정으로 MP1-03을 다시 명시 실행한다. 다른 계정으로 교체하는 작업은 이번 범위에 없다.

## 판단해서 정한 것

- 공통 업무실 권한을 풀지 않고 메신저만 허용: 다른 신규 기능의 접근 범위가 넓어지는 것을 피한다. 중지는 MP1-80으로 한다.
- 한 명·최대 7일: 임시 시험 요청에 맞춘 범위다. 일반 공개 정책으로 재사용하지 않는다.
- 작성 중 입력과 결과 미확정 요청은 현재 탭 메모리에 보존한다. 화면 재확인 중에는 같은 요청 번호로 복구하며, 계정 변경·시험 허용 취소 시 이전 화면을 숨긴다. 브라우저 종료 뒤 복원은 제공하지 않는다.
- 기존 SQL 파일은 수정하지 않았다. MP1 뒤에는 기존 P3-03/INT-08의 옛 함수 지문 대신 **MP1-02·INT-09**로 검사한다. 이전 점검의 원문 불일치를 무시하는 방식으로 진행하지 않는다.

## 자동 검증과 한계

`test/run_mp1.py`는 새 localhost PostgreSQL 17에 기존 통합 설치와 S1~S3를 먼저 실행한다. 운영 DSN·키를 받지 않는다. 실제 SQL 응답을 앱 parser에 넣고, 실제 Python HWPX 검사기를 사용한다. Storage는 RLS가 걸린 합성 객체 표와 메모리의 파일 바이트로 대조한다.

실제 Supabase/PostgREST·Storage 서비스·Vercel 왕복과 실제 사용자 로그인 시험은 적용·배포 후 위 순서로 진행한다. 자동 시험 성공을 운영 성공으로 표시하지 않는다. 결과 숫자는 PR과 `verification.md`에 기록한다.
