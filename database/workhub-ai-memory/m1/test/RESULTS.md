중점 확인:

- 정확한 create/update/delete 접수증, 같은 번호 재전송·recover·close, 다른 내용의 번호 재사용 거절.
- 삭제 후 제목·본문·기한 NULL, 감사/요청 원장에 원문 미복제, 과거 생성/수정 재전송에 의한 부활 차단.
- 다른 교사/학교 접근과 타 소속 위조 차단, 중지된 소속 차단, 같은 요청 번호의 소유자별 격리.
- 50개 저장 한도 경합, 같은 판 동시 수정, 원요청/닫기 경합 6회, 닫기 재확인.
- ID ASCII 목록 순서, 선택 요청 순서, 참조의 판·활성·기한·1~5개 한도, 혼합 선택 원자성.
- 만료일 당일 포함, 이미 만료된 날짜를 유지한 수정·중지, 과거 기한 신규 입력 거절.
- 학교 쓰기 중지 후 목록·삭제·복구·닫기 유지와 새 생성·수정·선택 거절.
- API 역할 직접 표 조회/내부 실행 차단, 원장 변조 차단, 보호 트리거·내부 실행권한·RLS 훼손 탐지 및 복구.
