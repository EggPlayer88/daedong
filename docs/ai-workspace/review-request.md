# Claude 검토 요청 — 대화 중심 업무 1~5차

기존 업무를 AI 대화 안에서 조회·검토·확정하는 연결을 검토해 주세요. PR #118 → #119 → #120 → #121 → 5차 후속 PR 순서로 쌓였으며, 최신 후속 PR의 기준 커밋과 CI를 먼저 확인해 주세요. 병합·운영 DB 적용·기능 활성화·일반 교사 공개를 요청하는 문서가 아닙니다.

## 구현 범위

- 일반 대화와 업무별 전문 지침, 간결한 입력 화면, 개인 할 일 변경·완료와 개인 일정 검토·등록.
- 메시지·수합·문서·질문형 HWPX의 기존 편집기·확인·접수 결과를 AI 안에 연결.
- 시간표·수업/학생·기록·학교 관리·인계의 기존 대상 선택과 승인 흐름 연결.
- 협업·학교 자료·공유/여러 날짜/일괄 일정 연결. 명시 복합 요청 최대 4단계, 원문 보존과 한 단계씩 실행.

- 오늘 업무·급식·알림 원본의 AI 내부 조회. 제목·상태 변경과 완료/취소한 할 일 다시 시작은 대상 선택·원본 비교·확인 후 저장.

## 중점 확인

1. **말과 실행의 구분:** 일반 조언·자료 인용·메시지 본문이 실행 명령이 되지 않는지. 복합 요청 일부만 실행하거나 다음 단계를 자동 시작하지 않는지. 선택 표시를 완료로 오해하게 하지 않는지.
2. **선택·확정:** 교사/학생/수업/학기/자료를 기존 권한 안에서 직접 고르는지. 공개·발송·제출·승인은 기존 최종 확인을 유지하는지.
3. **입력·복구:** 같은 편집기 중복 마운트, 입력 덮어쓰기, 날짜 변경 후 상대 날짜 재해석, 결과 미상일 때 새 요청 번호 발급이 없는지.
4. **원문 근거:** 학교 자료 ID·판·인용 위치와 학생 기록의 revision/hash/epoch가 이어지는지. 상담 자료를 AI 문맥으로 추가하지 않았는지.
5. **교차 흐름:** 메시지/문서/학교 자료에서 AI 조언 후 돌아오기, 수합 제출, 일정에서 수업 열기, 협업과 할 일, 원래 일반 메뉴가 계속 동작하는지.
6. **접근성:** 320px·확대 글씨·키보드 초점·처리 중 잠금/복귀. 실제 휴대폰 IME는 별도 미검증으로 남겨 주세요.
7. **비용·권한:** 기존 Haiku/Sonnet, 명시 정밀 검토, 예산/정산, 인증/RLS/메뉴 공개와 HWPX 엔진에 변경이 없는지. 무료 명령이 유료 요청으로 우회하지 않는지.

8. **일상 업무:** 조회 실패와 정상 0건을 구분하는지, 급식 날짜와 현재 권한 기준일을 혼동하지 않는지. 알림 원본 열기로 자동 읽음·완료가 되지 않는지. 제목·재개·상태 변경에서 다른 필드와 원키 복구를 보존하는지.
