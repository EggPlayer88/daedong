# 학교 구성·관계·학교 자료·실시 기록 결과 연결 — 12차 검증 기록

2026-11-12. PR #128 `0a8105cb` 위에서 작업했다. 기존 DB·RPC·인증·권한·공개 범위·AI 모델/비용·파일 생성 엔진을 변경하지 않는다. 새 SQL·환경변수는 없다.

기존 선택·검토·최종 확인 버튼을 유지한다. 화면을 열거나 내용을 검토한 것만으로 저장 결과를 만들지 않는다. 학교 자료 게시는 해당 자료의 적용 기간과 구분하며, 미실시 기록을 업무 전체 완료로 부르지 않는다. 결과 표시를 위해 별도 RPC나 유료 AI 호출을 추가하지 않았다.

## 확인·복구·개인정보 경계

- 기존 서버 접수 parser로 요청 번호·명령 종류·원본·판·시각을 대조한 뒤 최소 메타만 전달한다. 본문·학생/교사 이름·점수·사유·메모·파일 주소는 AI 결과 이력에 복제하지 않는다.
- 학교 구성은 `save_configuration`의 update/create_year만 연결한다. 접수증의 학년도와 명령의 구성 ID를 사용하며 기존 계약의 전역 판 증가를 따른다. 교사 소속 상태와 공식 담당 배정은 별도 명령이며 구성 저장 결과로 표시하지 않는다.
- 수업 관계는 기존 preview의 영향 전체와 정확한 다음 판을 검증한다. 원래 관계 ID와 수업을 고정하고 교체 때만 새 담당 ID를 보관한다. applied/replayed는 같은 원래 명령·번호이며 재시도로 이력을 늘리지 않는다. 전출은 전체 영향 관계 중 원래 대상의 판과 전체 건수를 사용한다.
- 학교 자료 생성/import는 1판, 변경/게시/종료는 기존 다음 판을 검증한다. 준비·업로드·추출·원본 다운로드를 초안 저장으로 표시하지 않는다. 가져오기의 각 통신 사이에서도 계정·학교·날짜·서비스 변경을 확인해 늦은 후속 처리를 중단하고 원키를 보존한다.
- 실시 기록은 검증된 command hash·수업 ID/판·기록 ID/판·outcome을 따른다. 복구·명시 재전송·이미 반영된 요청 닫기는 같은 접수증을 전달하며 단순 닫힘은 결과가 아니다. 현재 계약에 삭제·무효화 API는 없어 새로 만들지 않았다.
- 학교/계정/소속·기준일·전문 업무·검색 대상과 최초 원본을 고정한다. 다른 학년도·수업·관계·학교 자료·실시 기록을 같은 AI 단계에 합치지 않는다. 출력이나 공개와 이번 네 결과를 혼동하지 않는다.
- 서비스/날짜/계정/화면 교체 뒤 늦은 결과를 제외하고 시작한 callback만 사용한다. 보조 이력 표시·후속 목록 조회 실패가 완료한 요청의 재전송을 만들지 않는다. 기존 요청 번호와 작성 입력은 복구할 수 있게 유지한다.
- 결과 이력은 기존 탭 메모리다. 과거 단계를 다시 열어 자동 연결하거나 여러 장치에 동기화하는 기능은 추가하지 않는다.
