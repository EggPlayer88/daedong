# 2차 메시지·수합·문서 연결 검증

2026-11-11. PR #118 `e0a4494b`를 기준으로 `feat/ai-workspace-delivery`에서 구현한다.

## 검증 경계

실제 React, 연결 셸, 어댑터, 기존 서비스의 parser와 요청 복구를 사용하며 계정·DB·Storage·AI 응답은 합성이다. 운영 DB 쓰기, 실제 회원 변경, 외부 메시지 전송, 유료 AI 호출, 모델·비용 변경은 하지 않는다. 자동 시험의 성공을 실제 운영 왕복이나 AI 답변 품질 확인으로 표시하지 않는다.

## 주요 회귀

- 메시지 수신자 명시 선택·판 재확인, 확인 전 전송 0회, 같은 번호 복구, HWPX 첨부 검사와 미확정 업로드.
- 수합 초안과 공개 구분, 최종 제출의 파일/판/단위/기한 확인, 확인 이후 변경 무효화.
- 질문형 원본·미저장 답변·AI 요청 번호 보존, 생성물 다운로드/확인 뒤 수합 전달.
- AI 작업 패널과 일반 화면의 단일 편집기, 입력 보관과 복귀, 계정/학교 범위 분리.
- 작은 화면·큰 글씨·키보드 닫기 잠금, 조회 오류와 재전송 안내의 비노출 방지.

새 HWPX 흐름은 실제 Python 생성 코드를 사용하고 내려받은 파일의 해시를 대조한다. 수합 파일 예약·검사·저장·최종 제출은 합성 응답이지만 실제 앱 어댑터와 검증을 통과한다. 제출 대상 두 명의 기존 ZIP 실물 비교도 회귀에 포함한다.

최초 연결 시험 1곳은 기존 수합 페이지의 h1을 기대해서 실패했다. AI 안 수합 패널·URL·단일 편집기·쓰기 0회를 확인하도록 바꿔 15건을 재실행했고 모두 통과했다. 일부 파일 다운로드 시험은 Windows 제한 환경에서 취소되어 정상 로컬 권한으로 다시 실행했다. 이 실패를 통과로 계산하거나 데이터·권한·원요청 검증을 제거하지 않았다.

통합 도중 발견한 문제도 함께 고쳤다. 메시지와 수합 입력을 보관한 채 대화로 복귀하도록 했고, 다른 업무에 입력이 남아 있으면 새 답변 전달을 즉시 거절해 나중에 빈 작업으로 자동 전환되지 않게 했다. 권한이 없거나 없어진 수합에 전달한 생성 파일은 원본을 삭제하지 않고 선택만 해제할 수 있다. 미확정 요청·파일 처리 중에는 해제를 막는다.

실제 운영 사용자·Storage·AI 외부 왕복, 실제 휴대폰 키보드, AI 답변 품질, 전체 업무의 대화 완료율은 이번 자동 시험에 포함하지 않는다.
