AI가 기존 버튼을 대신 자동 확정하는 변경이 아니다. 기존 후보 선택·비교·확인·서버 접수가 끝나면 보관한 AI 업무 단계에 **처리 내역 확인**을 남긴다. 대기 중인 협업을 완료로 보이지 않게 하고, 활동 자료를 가져왔다는 이유로 관찰 기록이나 평가가 작성됐다고 표시하지 않는다.

## 출처와 복구

- 접수에 필요한 원본 ID·판·요청 번호·처리 종류·접수 시각만 복사한다. 본문·사유·명부·학생 이름·점수·수신자 목록은 결과 이력에 복제하지 않는다. 상담은 본문뿐 아니라 저장·정정·철회 사실도 전달하지 않는다.
- 작업을 시작한 계획 객체·단계 원문·학교/계정/소속·기준일·패널과 첫 원본을 고정한다. 검색 결과로 고른 일정·협업·수업과 다른 원본의 결과는 연결하지 않는다. 전문 관찰/평가/활동 업무에 다른 종류의 결과를 붙이지 않는다.
- 같은 수업이라도 별도 학생 기록, 다른 협업 요청, 별도 일정은 기존 단계에 붙지 않는다. 동일 기록의 수정·철회만 이어진다.
- 활동 정정은 기존 서버 계약상 새 import ID를 만든다. 검증된 명령의 `previousImportId`가 직전 결과의 ID와 같을 때만 이력을 잇는다. A→B→C는 허용하지만 이미 B로 바뀐 뒤 A에서 갈라지는 정정, 다른 수업, 과거 가져오기 결과를 다시 붙여 계보를 되감는 경우는 거부한다.
- 응답 유실은 원래 내용·번호로만 복구한다. 같은 key는 결과를 한 번만 기록한다. 서비스/날짜 변경 후 늦은 응답, 콜백 예외, 후속 목록 조회 실패가 추가 쓰기를 만들지 않게 했다.
- 단일 일정 어댑터는 CalendarEvent를 반환하므로 새 결과 보고 전에 원래 ID·다음 판·정규화한 입력 일치를 추가 확인한다. 보조 결과가 맞지 않으면 AI 이력에서 제외하며 기존 저장 경로를 새 계약으로 바꾸지 않는다. 일괄은 기존 검증된 prepareId와 선택한 전체 행의 접수증을 사용한다.
- 이력은 기존 탭 메모리이며 같은 열린 패널의 후속 처리에만 연결한다. 이미 닫은 과거 단계를 재연결하거나 장치 간 동기화하는 기능은 추가하지 않는다.

## #126 자동 검사 수정

#126 첫 CI는 1~8단계 SQL 대조에서 **2,289 PASS / 20 FAIL**이었다. 인계 서비스가 반환하도록 보존한 `version`·`recordedAt`을 고정 P7/P8 비교기가 예전 축약 결과와 비교해서 발생했다. `legacyDutyReceipt` 자체는 기존 비교에도 있었으며 원인이 아니었다.

확정 SQL과 원본 시험 파일·`SQL_REF`·원본 변경 금지 가드는 그대로 두었다. 실행기가 만드는 격리 시험 사본에만 다음을 적용한다.

1. 고정 P7/P8 비교기 원문의 SHA256과 정확한 비교식 위치를 확인한다. 예상과 다르면 중단한다.
2. 서버의 실제 `version`·`recordedAt`을 기대 접수증에 추가해 앱 반환값과 정확히 비교한다. 누락·다른 값은 실패하며 옛 축약 방식으로 자동 후퇴하지 않는다.
3. 원본 해시와 실제 실행 사본 해시를 source manifest에 따로 기록한다. SQL 변경은 0이다.

보정 코드 12건과 기존 실행기 안전 회귀 64건이 통과했다. 이 변경은 #126 `921646a6`으로 정상 push했으며 rebase·force push는 하지 않았다. 격리 PostgreSQL 대조와 CI의 최종 상태는 아래 기록으로 구분한다.

## 판단한 범위와 남은 작업

- **종료 상태를 추정하지 않는다:** 협업 완료 확인과 확인 대기, 평가 초안과 확인 저장, 활동 자료와 실제 기록을 구분한다. 보조 이력 연결을 제거해도 기존 화면과 실행·복구는 남는다.
- **수업 일괄 등록은 행별 접수:** 성공한 각 행만 결과를 내보낸다. AI 단계는 첫 수업 원본을 고정하므로 다른 행을 같은 수업의 완료로 합산하지 않는다. 전체/부분 성공은 기존 일괄 결과 화면에서 확인한다.
- **별도 계약은 별도:** 수업 관계 관리·학교 자료 정정·기록 출력, 시간표 공개/실시 기록, 학교 기초 자료·지식 게시의 결과 이력은 이번 범위 밖이다. 기존 기능은 계속 사용할 수 있다. 일정 삭제는 기존 편집기·어댑터 경로가 없어 추가하지 않았다.
- **연결 수치 유지:** 기존 61개 업무 중 내부 경로 55개, 대표 직접 회귀 근거 27개의 집계는 그대로 둔다. 새 경로 개수가 늘거나 자연어만으로 90% 완료한 수치가 아니다.
- **다음 순서:** 쌓인 PR의 CI와 검토를 마친 뒤 사용자 병합·배포. 남은 별도 계약의 결과 연결과 평가계획서 내부 작업·설정·외부 계산기 연결은 별도 범위다. 실제 운영 왕복·AI 답변 품질 평가는 자동 시험과 구분한다.
