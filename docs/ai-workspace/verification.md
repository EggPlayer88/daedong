# 1차 대화 업무 기반 검증

2026-11-11 · 합성 계정/자료와 실제 React·어댑터·프롬프트 조립 코드를 사용한다.

## 자동 확인 범위

- 분야별 자동/수동 선택, 질문 원문과 기존 자료 범위 보존, 일반 통찰과 학교 사실 근거의 분리.
- 미확정 AI 요청의 동일 분야/원문/요청 번호 재전송 및 정밀 검토 원요청 유지.
- 기존 할 일의 최신 원본/소유자/판 비교, 선택한 한 건만 수정/완료, 원키 복구.
- 개인 일정 누락 정보 보완, 공개 범위 고정, 명시 확인 전 저장 0건, 응답 유실 후 중복 방지.
- 계정 변경 중 사전 조회/저장 응답 무효화, 원문·명령·접수증 변조 차단.
- 기존 문서/수합 초안 연결, 근거 인용, 기억 관리, 학교 AI 비용 계약 회귀.
- 작은 화면·확대 레이아웃, 접힌 보조 메뉴, 키보드 포커스와 결과 안내.

## 실행 결과

최종 `npm test` **5,497건이 모두 통과**했다(Python 생략 없음). 첫 샌드박스 실행은 Windows 임시 폴더 정리와 로컬 HTTP 바인딩 제한으로 19개 파일이 실패했다. 정상 로컬 권한으로 다시 실행했고, 마지막 제목/검색 호환성과 입력 한도 보완까지 포함한 전체 결과다. 환경 실패를 제품 통과로 계산하지 않았다.

| 검증 | 결과 |
|---|---|
| `npm test` | 5,497건 통과 · 실패 0 · Python 생략 0 |
| `npm run check:workhub` | 통과 |
| `npm run build` | 통과. 기존 500KB 초과 청크 경고는 남음 |
| `npm run check:workhub:design` | 통과. 생성된 시간 기록 파일은 이번 변경에서 제외 |
| 분야·원문·한도·SQL 대응식 | JS 19 + Python 5건 통과. Python 안의 TS→Python 56조합 비교 포함 |
| 공통 개인 업무 실행기 | 16건 통과 |
| 관련 브라우저 전체 | 13개 파일, 서로 다른 시나리오 218건 통과 |

브라우저 구성: AI 기반 7, 공통 실행 10, 기존 AI 화면 25, 기존 AI 계약 화면 28, 모듈간 연결 28, 화면 정리 7, 실제 연결 셸의 업무 15, 기존 일정 편집기 8, 기존 대화 업무 19, 개인 기억 18, 학교 AI 정책 15, 근거 조회 20, 전체 시범 연결 18.

마지막 보완 뒤 AI 기반·공통 실행·화면 정리·실제 업무 연결 4개 파일(39건)을 다시 실행했다. 기존 테스트의 데이터·권한·정산 assertion은 유지하면서, 접힌 설정을 실제로 펼치거나 기존 편집기 대신 대화 검토 카드를 확인하도록 동작을 갱신했다. Chrome 320/390px와 큰 글씨, 어두운 스킨의 가로 넘침을 확인했다. 실제 휴대폰 키보드 시험은 포함하지 않는다.

## 검증하지 않은 것

이번 작업에서 운영 DB 쓰기, 실제 교사 자료 변경, Claude 유료 호출, 운영 배포를 하지 않았다. 따라서 답변 품질·실제 응답 시간·배포된 서버의 외부 왕복을 자동 시험 통과로 간주하지 않는다. 브라우저 화면은 실제 앱 코드지만 DB/AI 응답은 합성이다. 모든 기능의 대화 완료율 90%는 아직 측정 전이다.
