## 발견한 결함과 수정

### 1. 저장 성공 뒤 화면 갱신 실패를 결과 미상으로 안내

`useAssistantWorkspace`에서 새 개인 할 일 접수는 성공했지만 후속 `onUpdated`가 예외를 내면 바깥 오류 처리기로 넘어갔다. 합성 재현에서는 실제 저장 1건·보관 중 요청 0건인데도 같은 요청으로 결과를 확인하라는 안내가 나왔다.

정상 접수 이후의 보조 화면 갱신 예외만 분리했다. 저장 성공과 원본 링크를 유지하고, 갱신 실패를 별도로 안내한다. 최초 저장과 동일 요청 번호 복구 양쪽에 회귀를 추가했다. 저장 1회, 원키 유지, 미확정 요청 0건, 재확정 버튼 없음, 원본 열기를 검사한다.

### 2. 학교 자료 검색 원문에서 처리한 결과의 목록 연결 누락

`ConnectedWorkspace`의 자료 검색 결과 열기 경로가 결과 콜백을 전달하지 않았다. 선택한 자료를 게시해도 AI 목록에는 화면 연결됨만 남았다. 일반 전문 업무 열기 경로의 기존 계약을 그대로 사용해 콜백 전달을 복구했다.

수정 전 합성 게시 저장 성공 후 목록 누락을 재현했다. 수정 후 선택 원문의 게시 접수, 응답 유실 후 원키 복구, 다른 자료의 게시 결과 제외를 검사했다. 원문 조회만으로 처리 완료를 기록하지 않으며 추가 RPC나 AI 호출을 넣지 않았다.
