## 판단해서 정한 것

1. **현재 수업과 기본 배치 분리:** 기존 `TimetableAgendaWorkspace`를 사용해 변경·취소를 반영한다. 원본 실패를 기본표나 정상 0건으로 대체하지 않는다. 기본표는 기존 `PersonalRosterAgenda`의 참고 표시를 유지한다.
2. **전용 문서 화면은 새 탭:** 기존 제출 화면의 `File`·입력은 컴포넌트 메모리에 있고 전용 작성 화면은 통합 편집 잠금 계약을 아직 제공하지 않는다. 무리하게 AI 패널에 마운트/해제해 파일과 요청 복구를 잃지 않도록 명시 링크만 연결했다. AI 내부 완료로 집계하지 않는다.
3. **표시와 권한 분리:** 기간 업무 설정은 새 링크를 표시하는 조건이다. 이미 열린 전용 화면의 직접 접근 계약을 바꾸지 않으며, 기존 역할·공개 범위를 넓히지 않는다.
4. **추가 비용 없음:** 명시 화면 열기와 오늘 수업은 기존 로컬 분류·조회만 이용한다. AI 조언과 파일 생성은 기존 확인·정산 흐름을 유지한다.
5. **되돌릴 지점:** 이번 앱 연결을 되돌리면 일반 시간표·평가계획서 메뉴가 남는다. 새 SQL·자료 변환·환경변수가 없어 데이터 되돌리기는 필요하지 않다.
