## 원본·개인정보·응답 유실

- 원본 ID·판·요청 번호·처리 종류·시각·개수와 출력 범위만 복사한다. 학생 이름·관리 번호·기록 본문·점수·정정 사유·상담 자료는 결과 이력에 복제하지 않는다.
- 학교 자료는 기존 명령/접수증 parser로 `kind`·원본·다음 판·요청 번호·접수 시각을 대조한다. 닫기 응답이 이미 반영됨이면 원래 접수증을 사용하고, 단순 닫힘이면 결과를 기록하지 않는다.
- 시간표는 일반 공개와 명세 공개의 기존 검증된 접수증을 사용한다. 명세 hash·기준판·변경 건수를 대조하고, 승인·학사 변경을 공개로 분류하지 않는다. 복구·같은 번호 재전송·이미 반영된 요청 닫기도 동일 경로로 연결한다.
- 출력에는 서버 접수 시각을 만들지 않는다. `observedAt`은 클라이언트의 자료 확인 시각이다. 출력 직전 재조회와 fingerprint 대조를 유지한다. 자료 변경·접근 오류·차단된 인쇄 창·빈 출력은 출력 성공 이력을 만들지 않는다. 0건 미리보기는 가능하다.
- 계획/단계·학교/계정/소속·기준일·전문 업무와 첫 원본을 고정한다. 다른 수업·학생·공개 원본·출력 기간/선택 범위를 기존 단계에 합치지 않는다. 관찰 전용/평가 전용 전문 업무에 혼합 출력 결과를 붙이지 않는다.
- 서비스·날짜·계정 변경이나 화면 종료 뒤 늦은 결과는 무시한다. 응답 유실 시 원래 요청 번호를 보존한다. 결과 콜백 또는 후속 조회 실패가 이미 반영된 업무의 재전송을 만들지 않는다.
- 결과 이력은 기존 탭 메모리다. 닫은 과거 업무와 자동 재연결하거나 여러 장치에서 동기화하는 기능을 추가하지 않았다.

미리보기 후 이미 처리한 단계 번호를 다시 선택할 때 기존 공통 문구가 “서버 처리 확인”이라고 안내하는 오류도 수정했다. 업무 결과 이력은 “처리 내역 확인”으로 안내하고, 실제 개인 업무의 서버 접수 확인 문구는 유지한다.
