# 업무혁신시스템 누적 진행 현황

최종 갱신: 2026-10-14 · 운영 연결 조사 도구와 B00 인계

현재 목표는 **문서작성 AI·시간표를 제외한 기능을 실사용 가능한 형태로 완성한 뒤 시범 공개**하는 것이다. 사용자 승인으로 **DB 준비를 재개**했다. 확정 SQL은 Claude Web이 작성하고 사용자가 검토 후 직접 적용한다. 문서작성 AI·시간표 구현은 계속 보류한다.

## 이번 작업

- 배포된 앱의 공개 연결 설정과 학교 조회 API를 제한된 GET 요청으로 확인하는 도구를 추가했다. 키·세션·응답 본문을 보고서에 남기지 않으며 앱의 인증·권한 코드는 바꾸지 않는다.
- 익명 조회의 오류·확인 불가·역할별 API 노출을 구분한다. PGRST202를 실제 함수 부재로, HTTP 200을 학교 연결 완료로 해석하지 않는다.
- Claude Web에게 전달할 [B00 읽기 조사 요청과 결과 해석](28-connection-audit-handoff.md)을 구체화했다. 7개 RPC의 서명·권한·선행 객체와 기존 회원·문서·파일의 보존 기준을 명시했다.
- 사용자 진단은 로그인·기존 승인·이용 권한 단계를 통과하고 학교 조회에서 중단됐다. 공개 배포 정보로 수행한 익명 요청에서도 PGRST202를 관측했다. 의도한 운영 프로젝트와의 일치 및 실제 DB 카탈로그 상태는 아직 미확인이다.
- 이번 도구 실행이나 PR 병합은 DB 함수 생성·학교 개설·회원 소속 연결을 수행하지 않는다.

[#26](https://github.com/EggPlayer88/daedong/pull/26)은 내 업무 화면 분리와 작은 동선 보완의 검토 대기 PR이다. #26·#27·#28 및 이번 작업은 main 기준의 **독립 변경**이며 서로의 기능을 포함한 통합본이 아니다. 먼저 병합된 변경은 다음 PR에 merge한 뒤 다시 확인한다.

**전체 90% 실사용 목표는 아직 달성하지 않았다.** 화면 구현·합성 검증·실제 저장·현장 검증을 구분한다.

## 검증 기록

- 운영 main(#25)의 기존 기준: npm 회귀 1,227건(Python 포함), 고정 Chromium 29/29 파일, 두 앱 빌드 통과.
- #27 기준: npm 1,255건, 브라우저 30/30 파일, 두 앱 빌드·CI·Vercel 통과.
- #28 기준: npm 1,244건, 정적 설계·18개 원본 지문/64개 링크·CI·Vercel 통과. F1~F9 전체 해결을 뜻하지 않는다.
- 이번 브랜치 전체 npm 회귀 **1,252건(Python 포함)** 통과. 새 연결 도구의 합성 HTTP 시험 **25건**이 포함된다. GET 범위·키 미노출·리디렉션/잘못된 대상 차단·응답 제한과 해석을 검증했다. 실제 공개 배포 조회 결과와 관측 한계는 [인계 기록](28-connection-audit-handoff.md)에 있다.
- 각 브랜치의 시험 수를 합산하지 않는다. 실제 회원 로그인·DB 쓰기·Storage 실물 복원을 이번 익명 조사로 검증한 것으로 표시하지 않는다.

## 다음 순서

1. #26·#27·#28과 이번 조사 도구 교차검토. 자동 검사·사용자 확인 후 사용자 병합.
2. 의도한 운영 프로젝트 대조 → Claude Web의 B00 읽기 조사본 검토 → 사용자 실행 → 상태별 원인 판정.
3. F5·기초 F6 및 현재 앱 계약 차이를 해결한 B01/B02 확정본·검증·복구 묶음 검토.
4. 사용자 격리 환경 적용 → 기존 계정의 학교 연결·일정/업무 저장·재조회·충돌/회수 확인. 운영 적용은 그 결과를 보고 진행.
5. 공통 파일 → DM/첨부·직접 파일형 수합 → 학생/수업 활동 → 학교 자료·Claude 상담/비서 → 관리·알림·인계/복구.
6. [시범 공개 조건](17-pilot-release-plan.md)의 실제 교사 과제·격리·복구·성능·접근성 검증 후 공개.
