# 업무혁신시스템 누적 진행 현황

최종 갱신: 2026-10-11 · 5차 개발 · 공통 사이트 구조와 화면 연결

이 문서는 **이번 작업 / 누적 진행 / 남은 작업 / 검증 / 판단해서 정한 것**의 인계 기준이다. 화면 구현·코드 검증·실제 서버 연결·운영 공개를 구분하며 테스트 수를 출시 완성률로 계산하지 않는다.

## 이번 작업 — 5차 개발

- 실제 연결 화면과 미리보기를 같은 사이트 틀로 통합했다. 오늘·학교 일정·내 업무·자료 수합·수업과 학생의 위치와 관계, 학교 맥락, 모바일 더보기, 오류 복구를 공통화했다.
- 화면 주소의 직접 진입·새로고침·뒤로/앞으로 이동을 연결했다. 메뉴뿐 아니라 홈 바로가기·학교 전환·기존 앱 링크에서도 작성 중 입력을 보호한다.
- 일정의 월·주·목록 보기, 검색, 관련 일정 필터, 날짜 이동, 홈의 다가오는 7일 요약을 구현했다.
- 개인 업무는 미리보기와 실제 연결에서 같은 화면을 쓴다. 수합·학생 입력 보호를 보강하고 저장 후 이동 잠금·공백 정규화·Unicode 한도 불일치를 수정했다.
- 일정 저장의 응답 유실 시 원래 요청 번호와 입력으로 결과를 다시 확인하도록 했다. 접수 후 응답만 사라지는 경우에도 신규 중복·수정 버전의 이중 증가가 없음을 확인했다.
- 바탕화면에 서버 없이 열리는 **5차 기본 구조 HTML**을 저장했다. 합성 자료만 사용하며 실제 서버에 접속하지 않는다.
- **시간표 작업은 사용자 요청에 따라 보류. 사이트 AI는 Claude를 전제로 진행.** 이번 작업에서 모델·API 키·비용 설정을 바꾸지는 않았다.

수합·학생 기능은 현재 미리보기에만 연결한다. 실제 앱의 연결 메뉴는 준비된 일정·개인 업무까지만 사용한다. 기본 틀이 통합됐다고 모든 모듈의 서버 저장이 끝난 것은 아니다.

## 남은 작업 순서

1. **검토본 통합 준비:** 선행 PR부터 Claude 교차 검토와 사용자 화면 확인. 의존 순서를 지켜 병합한다.
2. **실제 연결:** 계정 보존/복구 점검 → 제안 SQL 확정 → 격리 검증 환경 적용 → 기존 계정과 학교 소속 연결. SQL 확정은 Claude Web, 실제 적용과 main 병합은 사용자 담당이다.
3. **일정·개인 업무 실사용 실증:** 실제 Google 계정 진입 → 등록·조회·수정·홈 반영 → 두 실제 계정의 열람/충돌/승인 회수/소속 종료 확인.
4. **수합 서버 전환:** 초안 비공개·상태 전이·접수·검토 권한을 서버에서 강제하고 파일·문서 초안을 연결한다.
5. **학생 자료 연결:** 담당·명부·작성자 권한·보존/삭제를 적용한 뒤 디지털윤리 수업 사이트와 연결한다.
6. **Claude·문서 통합:** 학교 지식의 근거·유효기간·학교 범위, 개인 비서와 문서 도구 계약을 구현한다. 시간표는 별도 재개 요청 후 진행한다.
7. **교사 파일럿·전국 운영 검증:** 홈 정보량·모바일 동선·접근성, 실제 사용성과 성능·복구·인계·반복 업무를 검증한다.

실제 연결에 필요한 검증 DB 설정과 기존 로그인 세션은 별도 준비 사항이다. 임의 계정 재생성이나 운영 DB 초기화로 대체하지 않았다.

## 판단해서 정한 것

1. **공통 틀을 우선 통합:** 기능을 늘려도 메뉴·학교 맥락·이동 보호가 일관되도록 했다. 수정 위치는 `modules.ts`, `WorkspaceShell`, `navigation`이다.
2. **미저장 상태는 명시적 저장·취소 후 이동:** 세부 임시 저장 정책을 추정하지 않고 조용한 입력 유실을 막는다. 변경 위치는 `EditSession`과 각 편집기다. 강제 종료 후 미확정 요청 복구는 후속 과제다.
3. **검증된 경계를 유지하며 신축:** 로그인·회원·문서 엔진·SQL 확정본·운영 공개 범위를 보존한다. 실제 서버로 전환할 때는 모듈 어댑터와 서버 계약을 검증한다.
4. **Claude 전제와 시간표 보류 유지:** AI의 해석·초안·제안과 프로그램의 권한·계산·확정 반영을 분리한다. 모델·키·비용 선택은 아직 실행하지 않았다.

개인 업무는 현재 학교·소속 단위다. 학교와 무관한 개인 공간, 전출 시 이관, 대규모 목록 페이지 처리, 실제 자료의 보존·삭제 정책은 아직 남아 있다.
