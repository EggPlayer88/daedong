# 업무혁신시스템 누적 진행 현황

최종 갱신: 2026-10-13 · 9차 개발 · [PR #16](https://github.com/EggPlayer88/daedong/pull/16) (기준 PR #15)

이 문서는 **이번 작업 / 누적 진행 / 남은 작업 / 검증 / 판단해서 정한 것**의 인계 기준이다. 화면 구현·코드 검증·실제 서버 연결·운영 공개를 구분하며 테스트 수를 출시 완성률로 계산하지 않는다.

## 이번 작업 — 9차 개발

- 개인 업무의 등록·수정·취소·완료 뒤 사라지는 버튼에서 초점이 유실되지 않도록 수정했다. 오류와 충돌 원본 재조회는 안내로, 최신 내용 사용은 제목 입력으로 이어진다.
- 일정 편집기의 **일반 DOM / ShadowRoot** 초점 복귀를 함께 보완했다. 저장 후 목록 재조회는 완료 안내로, 필터·전체 기간 변경은 검색 입력으로 연결한다.
- 모바일 더보기의 Escape 닫기·현재 메뉴 재선택, 320px 메뉴 배치와 일정 모달의 좁은 너비·낮은 높이 조작을 보완했다.
- 수합의 반복 필드에 고유 레이블·단위 설명을 연결하고, 생성·단위 추가/삭제·게시·응답·검토·의견 취소·원본 비교·표 페이지 이동 뒤 초점을 유지했다.
- 학생 기록의 정정·철회·활동 연결·채택·취소·조회 복구 뒤 초점을 이어 주고 반복 폼의 이름·설명을 보강했다. 긴 원자료·불변 이력의 가로 넘침도 수정했다.
- 바탕화면에 서버 없이 열리는 **9차 사용성과 접근성 HTML**, 검증 이미지·JSON, 누적 진행 보고서를 제공한다.
- **DB 구축·시간표는 계속 보류. AI는 Claude 전제 유지.** 기존 로그인·회원·인증·권한·SQL·보호 자산·외부 설정·운영 공개 범위는 변경하지 않았다.

수합·학생 기능은 현재 미리보기에만 연결한다. 실제 앱의 연결 메뉴는 준비된 일정·개인 업무까지만 사용한다. 기본 틀이 통합됐다고 모든 모듈의 서버 저장이 끝난 것은 아니다.

## 남은 작업 순서

1. **검토본 통합 준비:** 선행 PR부터 Claude 교차 검토와 사용자 화면 확인. 의존 순서를 지켜 병합한다.
2. **DB 보류 중 화면 개발:** 작성·조회 동선의 사용자 피드백을 반영하고, 실제 교사의 키보드·화면읽기·확대 사용을 확인하고 오류 복구와 실제 규모의 목록 성능을 보완한다. 학교 자료·문서 작업 공간은 기존 청사진·도구 계약을 바탕으로 설계하되 실제 AI·서버 연결 준비와 구분한다.
3. **DB 재개 후 실제 연결:** 통합 설계 [PR #12](https://github.com/EggPlayer88/daedong/pull/12) 확정 → 계정 보존/복구 점검 → 격리 검증 환경 적용 → 기존 계정·학교 소속 연결 → 일정·개인 업무 실사용 실증. SQL 확정은 Claude Web, 실제 적용과 main 병합은 사용자 담당이다. 두 실제 계정의 열람/충돌/승인 회수/소속 종료를 확인한다.
4. **수합 서버 전환:** 초안 비공개·상태 전이·접수·검토 권한을 서버에서 강제하고 파일·문서 초안을 연결한다.
5. **학생 자료 연결:** 담당·명부·작성자 권한·보존/삭제를 적용한 뒤 디지털윤리 수업 사이트와 연결한다.
6. **Claude·문서 통합:** 학교 지식의 근거·유효기간·학교 범위, 개인 비서와 문서 도구 계약을 구현한다. 시간표는 별도 재개 요청 후 진행한다.
7. **교사 파일럿·전국 운영 검증:** 홈 정보량·모바일 동선·접근성, 실제 사용성과 성능·복구·인계·반복 업무를 검증한다.

실제 연결에 필요한 검증 DB 설정과 기존 로그인 세션은 별도 준비 사항이다. 임의 계정 재생성이나 운영 DB 초기화로 대체하지 않았다.

## 판단해서 정한 것

1. **저장 성공과 편집 취소의 도착 위치를 구분:** 저장은 결과 안내, 취소는 원래 버튼·기록·입력으로 이어 준다. 목록 재조회나 필터로 카드가 사라져도 처리 결과를 확인할 수 있다. 변경 위치는 TaskPanel, CalendarPanel, WorkflowPanel, StudentsPanel이다.
2. **실제 DOM 범위 안에서 초점을 관리:** 연결 화면의 ShadowRoot 안에 있는 버튼을 기억한다. 변경 위치는 EventEditor이며 일반 화면도 같은 구성요소로 확인했다.
3. **고유 필드 연결과 기존 조작 유지:** 반복 필드의 이름·단위·학생 맥락을 연결하고 기존 버튼 명칭·Tab 순서를 유지한다. 수합·학생 입력, 개인 업무 카드가 대상이다.
4. **기존 입력·저장 보호 유지:** 초점을 옮겨도 미확정 저장을 취소하지 않으며 충돌 원본을 자동 덮어쓰지 않는다. 저장소·명령·권한은 변경하지 않았다.
5. **작은 너비와 낮은 높이를 따로 보완:** 원문을 자르지 않고 줄바꿈하며 일정 모달 하단을 낮은 화면에서 함께 스크롤한다. 위치는 공통·셸·영역별 CSS다.

개인 업무는 현재 학교·소속 단위다. 학교와 무관한 개인 공간, 전출 시 이관, 대규모 목록 페이지 처리, 실제 자료의 보존·삭제 정책은 아직 남아 있다.
