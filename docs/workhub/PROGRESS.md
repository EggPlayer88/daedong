# 업무혁신시스템 누적 진행 현황

최종 갱신: 2026-10-13 · 13차 Claude 검토 반영 (기준 PR #19)

목표는 **문서작성 AI·시간표를 제외한 기능을 완성한 뒤 시범 공개**하는 것이다. **DB 구축과 시간표는 계속 보류**한다. 구현·합성 검증·실제 서버 연결·운영 공개를 구분한다.

## 이번 작업

- 일시 연결 실패와 화면 이동 후에도 원래 요청으로 저장 결과를 확인한다. 업무/일정/시트 입력창을 접고 읽기 화면으로 이동할 수 있다.
- 보완 제출과 일반 정정을 구분하고 학생 기록 정정의 학적 잔존 오류를 수정했다.
- 한국어 날짜/시간 입력을 지원하며 값이 있는 미연결 열은 확인 없이 제외하지 않는다.
- 검색 안내 문구를 검색어에서 제외하고 제목/본문/장소/날짜 검색을 유지했다.
- 권한 거부·입력 접기·시트 편집 취소 후 초점을 복원하고 신규 업무의 해당 쪽으로 바로 이동한다.
- 학생/활동 데모 기록을 현재 탭 메모리로 제한했다. 이전 v2 원본과 로그인 데이터는 삭제하지 않았다.
- 고정 Chromium 브라우저 24파일을 PR 필수 test 검사 안에 추가했다.
- DB v1을 그대로 최종 SQL 기준으로 삼지 않도록 인계 상태만 정정했다. 설계·SQL·운영 DB 변경은 없다.

|---|---|---|

| 로그인·회원 | 기존 공유 인증과 회원 보존, 읽기 진단, 실패 시 화면 폐기 | 실제 OAuth·신축 학교 연결 검증 남음 |
| 홈·내 업무 | 기한 요약·검색·20개 표시·등록/수정/상태·저장 복구·등록 원본 이동 | 통합 DB 대응·실제 계정 시험 남음 |
| 일정·시트 | 월/주/목록·대상·검색·충돌·응답 복구·시트 행별 입력·누락 확인 | 실제 서버 왕복·원본 ID 원장·일괄 처리·변경 대조 남음 |
| 자료 수합 | 공동 초안·책임 제출·검토·보완·정정·철회·완료 집계·진행표·페이지 | 합성 연결, 실제 서버·파일 제출/다운로드·다른 응답 유형 남음 |
| 학생·수업 기록 | 합성 명부·본인 관찰/정정/철회·활동 연결·검색/필터·출력·페이지 | 실제 명부·서버·상담·평가·디지털윤리 연동·보존/삭제 남음 |

| 운영·관리 | 공통 상태/오류/연결 진단·브라우저 자동검증 | 업무분장·협조·알림·문의·학기 전환·실행 인계·관리/복구 화면 남음 |
| DB·전국 서비스 | 다학교 경계 설계와 일부 격리 시험 | v1.1 정합성 보완·승인 SQL·파일 격리·부하·복원·학교급 현장 검증 필요 |
| 문서작성 AI·시간표 | 기존 코드·검토 기록·보호 자산 보존 | 계속 보류 |

수합·학생은 합성 저장소에 연결한다. 실제 연결 메뉴는 오늘·일정·내 업무다. **현재 미리보기는 검토할 수 있지만 전체 서비스 시범 공개 준비가 끝난 것은 아니다.**

## 검증

- 전체 npm 회귀 **1,194건**, Python 포함 통과.
- 타입 검사·기존 앱·신축 앱 빌드 통과.
- 고정 Chromium **24/24 파일** 통과: 이름 있는 시나리오 288개 + 별도 일정 보기 묶음 검증.
- 전달용 독립 HTML 자체의 오프라인 시험 **11개** 통과. 외부 HTTP 요청·브라우저 오류 없음.
- 로컬 Chromium 결과와 GitHub Actions 결과는 구분한다. 실제 운영 DB 왕복·전국 운영 인증을 의미하지 않는다.
- 상세 결과: [13차 검토 반영](20-review-recovery.md).

## 남은 작업 순서

1. **현재 수정 검토:** Claude 교차검토와 사용자 미리보기 확인, 선행 PR과 수정 PR의 통합 순서 정리. 병합은 사용자 담당.
2. **UI·UX:** 실제 교사 과제로 홈 정보량·동선·모바일 메뉴를 다듬고 실제 TSV 복사 표본, 자정 기준일 갱신, 기존 앱 초기 번들/이동 처리 등 후순위 지적을 확인한다.
3. **DB 재개 전:** v1.1 배치·시간표 참조·outbox·상속 제약/기본값·학생/수합 정상 경로·파기 계약 보완. [DB 인계](16-pilot-db-activation.md)는 재개 시 참고용이다.
4. **실제 데이터 연결:** 승인된 SQL 이후 일정/업무·공통 파일·수합·실제 명부/수업·학생 자료를 연결한다.
5. **기획상 나머지 기능:** 학교 자료·Claude 상담/비서·알림·업무분장·관리·학기 전환·인계/복구를 구현한다.
6. **시범 공개 후보 검증:** 교사 과제·다계정/다학교 권한·접근성·부하·복원·공개표를 점검한다. [시범 공개 계획](17-pilot-release-plan.md)의 P01~P11이 기준이다.

## 판단과 한계

- 미확정 요청은 현재 탭 메모리에만 보관한다. 새로고침 후 복구나 영구적인 서버 접수 조사까지 구현한 것은 아니다.
- 확정된 계정/권한 변경에는 이전 자료와 보관 명령을 폐기한다.
- 기존 학생 데모 원본을 삭제한 것은 아니다. 자동 로드와 새 영속 저장을 막았다.
- UI·UX의 기본 화이트/차콜·블루 방향과 메뉴 구성은 유지했다.
- [12차 UI 인계](19-calm-ui.md), [13차 상세 인계](20-review-recovery.md)를 함께 참고한다.
