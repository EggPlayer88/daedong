# 업무혁신시스템 누적 진행 현황

최종 갱신: 2026-10-13 · 15차 일상 사용 보완 (통합 PR #23 후속)

현재 목표는 **문서작성 AI·시간표를 제외한 기능을 완성한 뒤 시범 공개**하는 것이다. **DB 구축과 시간표는 계속 보류**한다. 구현·합성 검증·실제 서버 연결·운영 공개를 구분한다.

## 이번 작업

- 통합 PR #23의 검토 커밋은 유지하고 별도 브랜치에서 날짜 전환·일정 입력을 보완했다. [15차 상세](22-daily-use.md).
- 자정과 숨김 탭/절전 복귀 때 서버 기준일을 다시 확인한다. 날짜만 바뀌면 작성 중 입력과 미확정 저장 요청은 보존한다.
- 기기 날짜는 갱신 신호로만 쓰며, PC 시계가 빠른 경우 최대 3회 추가 확인한다. 겹친 조회는 순차 처리한다.
- 연도가 있는 날짜 뒤 한국어 요일을 지원하고, 실제 날짜와 요일이 다르면 등록 전 원본 수정을 요구한다.
- 통합 후보에는 사이트/기획 19개 PR의 이력과 최신 통합 설계 v1.1이 포함되어 있다. [통합 순서·구조](integration/README.md).
- #3 운영 자동화와 #5 시간표 엔진은 별도다. 실제 DB 구축·시간표·main 병합은 진행하지 않았다.

수합·학생은 합성 저장소에 연결한다. 실제 연결 메뉴는 오늘·일정·내 업무이며 준비된 학교/서버가 있어야 작동한다. **통합 후보와 미리보기를 검토할 수 있지만 전체 서비스 시범 공개 준비가 끝난 것은 아니다.**

## 현재 검증

- 전체 npm 회귀 **1,215건**(Python 포함), 타입·기존 앱/신축 앱 빌드 통과.
- 고정 Chromium **27/27 파일**, 전달용 독립 HTML **11개** 통과. 경합 검사 보완과 검증 한계는 [15차 상세](22-daily-use.md)에 기록했다.
- 통합 PR 19개 이력 포함·보류 2개 제외·기존 보호 범위·SQL 제안 보존.
- 설계 정적 검사 오류/경고 0, 로컬 링크 61개, 데스크톱 원본 18개 지문 일치.
- 상세 범위·번들 측정·미검증 항목은 [통합 검증 기록](integration/verification.md)을 참고한다. 원격 CI는 통합 PR의 최신 커밋에서 확인한다.

## 다음 작업

1. **통합본 병합 준비:** Claude 교차검토 → 남은 지적 해결 → 사용자 화면 확인 → 사용자가 main 병합 → 포함된 이전 PR 정리.
2. **보류 기간에도 가능한 UI·품질 작업:** 실교사 과제·실기기·실제 시트 표본, 필요한 화면/상태 분리.
3. **DB 재개 후:** [통합 DB v1.1](database-integrated/README.md)과 현재 코드 차이 확정 → Claude Web SQL → 사용자 적용 → 실제 일정/업무 왕복·공통 파일·수합·학생 연결.
4. **AI 없는 선행 흐름:** 기본 DM/파일 전달·직접 파일형 수합을 AI 분석/자동 생성과 분리해 연결한다. 시간표 동작은 보류한다.
5. **나머지 기능 및 시범 공개:** 학교 자료·Claude 상담/비서·알림·업무분장·관리·학기 전환·인계/복구와 [시범 공개 조건](17-pilot-release-plan.md)을 완료한다.
