# 업무혁신시스템 누적 진행 현황

최종 갱신: 2026-10-14 · DB 연결 준비 재개와 학교 초기 설정 준비

현재 목표는 **문서작성 AI·시간표를 제외한 기능을 실사용 가능하게 완성한 뒤 시범 공개**하는 것이다. 사용자 답변에 따라 **DB 준비를 재개**했다. 확정 SQL은 Claude Web이 작성하고 사용자가 검토 후 직접 적용한다. 문서작성 AI·시간표는 계속 보류한다. 구현·합성 검증·실제 서버 연결·운영 공개를 구분한다.

## 이번 작업

- 학교 연결 전에도 쓸 수 있는 최고관리자용 **학교 설정 준비** 화면을 구현했다. 학교·학년도·학기·부서·학급 입력, 검사, 작성 초안 불러오기/내려받기, 검토 계획 내려받기를 제공한다. [상세와 되돌림](26-school-setup-preparation.md).
- 윤년과 학기 중첩, 손상 파일, 입력 보존, 이동 보호, 오류 항목 초점, 모바일·키보드 동선을 검사한다. 기존 로그인·회원·공개 범위는 유지했다.
- 현재 연결 코드의 7개 구 RPC와 통합 DB 목표의 계정·소속·역할·기간 계약 차이를 재확인했다. 단순한 함수명 교체로 연결할 수 있는 상태는 아니다.
- 별도 DB 설계 보완에서는 F1~F9의 선행 조건을 정리하고, 상속 제약의 실제 모순을 수정하는 작업을 진행한다. 화면 PR의 완료를 DB 적용 준비 완료로 표시하지 않는다.

수합·학생은 합성 저장소에 연결한다. 실제 연결 메뉴는 오늘·일정·내 업무이며 준비된 학교/서버가 있어야 작동한다. **90% 실사용 목표는 아직 달성하지 않았다.** 실제 서버 저장과 파일·메신저·지식/비서·관리 흐름의 완성이 필요하다.

## 검증

- 기존 main(#25)의 기준: npm 회귀 1,227건, 브라우저 29/29 파일, 타입·두 앱 빌드 통과.
- 이번 학교 설정 PR: **npm 회귀 1,255건**(Python 포함), **고정 Chromium 30/30 파일**(학교 설정 12개 시나리오 포함), 타입·기존 앱/신축 앱 빌드 통과.
- 실제 호스트 CSS를 포함한 설정 화면을 320/390px와 데스크톱에서 확인했다. 운영 DB 왕복 시험은 포함하지 않는다.
- 과거 DB 정적 검사 통과는 F1~F9 지적 해결이나 운영 SQL 검증을 뜻하지 않는다.
- 최종 원격 CI는 해당 PR의 최신 커밋에서 확인한다.
