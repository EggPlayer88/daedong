수합·학생은 합성 저장소에 연결한다. 실제 연결 메뉴는 오늘·일정·내 업무이며 준비된 학교/서버가 있어야 작동한다. **통합 코드가 main에 반영됐지만 전체 서비스 시범 공개 준비가 끝난 것은 아니다.**

## 현재 검증

- 전체 npm 회귀 **1,227건**(Python 포함), 타입·기존 앱/신축 앱 빌드 통과.
- 고정 Chromium **29/29 파일** 통과. 새 연결 동선 9건 포함. 전달용 독립 HTML 11개의 이전 검증 기록과 한계는 [15차 상세](22-daily-use.md)에 있다.
- 통합 PR 19개 이력 포함·보류 2개 제외·기존 보호 범위·SQL 제안 보존.
- 기존 설계 정적 검사 오류/경고 0, 로컬 링크 61개, 데스크톱 원본 18개 지문 일치 기록은 유지한다. 정적 검사 통과는 F1~F9 설계 지적 해결이나 SQL 작성 준비 완료를 뜻하지 않는다.
- 상세 범위·번들 측정·미검증 항목은 [통합 검증 기록](integration/verification.md)을 참고한다. 원격 CI는 해당 후속 PR의 최신 커밋에서 확인한다.
