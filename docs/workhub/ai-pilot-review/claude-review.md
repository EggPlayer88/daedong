중점 확인:
1. B1 계획 instance/단계/원질문/접수증 연결. 확정된 할 일을 다시 선택할 수 없는지, 결과 유실은 원키로 복구하고 다른 계획에 늦은 응답이 붙지 않는지.
2. B2·B7·B9 자연스러운 표현과 날짜·검색어. 검토 중 ‘대상 이어 입력’ 뒤 원 일정 유지, 후보 직접 선택, 저장중/미확정 요청의 잠금 유지.
3. B4 같은 탭 새로고침 복구. 계정·학교 소속 재검증 전 비노출, 사용자 선택 뒤 복원, 자동 재실행 없음, 원키 보존, 파일 재선택, 로그아웃/계정 변경 폐기. 모든 모듈이나 브라우저 종료 뒤 복원을 보장하지 않습니다.
4. B5·R11 실제 메뉴/검색 범위에 맞는 예시·관리 탭. 교사 권한을 넓히지 않았는지.
5. B6 날짜별 확정 수업이 없을 때 기본표임을 명시하는지. 기본표로 날짜별 운영·휴업·교환이 반영됐다고 오인시키지 않는지.
6. B10 원본 없는 질문형 수합 차단과 오류가 AI 내부에 보이는지. 기존 문서/수합 화면에서 원본을 가지고 시작하는 경로 유지.
7. R6 완료 결과만 다음 요청에서 접는지. 미저장 입력·결과 미상·파일 전달 대기를 지우지 않는지.
8. NT1 새 알림 SQL: 원래 메시지/공개 트랜잭션에 연결, 본인 제외, 학교/소속/참여자 범위, 중복 제거, 알림 실패 전체 롤백. 기존 확정 SQL은 교체하지 않았습니다.

NT1은 운영 미적용입니다. 검토 뒤 사용자와 `INT-14 → NT1-00 → NT1-01 → NT1-02 → NT1-00 비교 → INT-15` 순서로 별도 진행합니다. NT1-01 성공 직후 새 메시지·답장·수합 공개 알림이 동작하며 별도 켜기 단계는 없습니다. 과거 누락 알림은 소급하지 않습니다.

실사용 재시험은 배포/SQL 적용 이후 기존 시험 계정과 자료로만 진행해 주세요. 실제 자료·권한·비용 정책은 그대로입니다. API 호출은 기존 승인 예산 안에서 최소화하고, 표현·오류·재전송은 먼저 합성 시험을 사용해 주세요. 계정 만료일이나 권한을 임의 연장하지 말아 주세요.
