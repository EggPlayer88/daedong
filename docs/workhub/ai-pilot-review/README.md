## 복구 저장의 범위

입력은 같은 탭에서 최대 12시간 보관한다. 결과 미상 원요청은 단순 만료로 버리지 않는다. 소속·역할이 달라지거나 로그아웃하면 이전 입력을 다시 노출하지 않는다. 파일·API 키·비밀번호와 일반 AI 초안의 대화 이력/학생 근거 본문은 보관하지 않는다. 이미 보낸 미확정 요청은 정확한 복구에 필요한 원명령을 별도 보관하며 자동 실행하지 않는다. 저장 공간이 없으면 이전 저장본을 남겨 오인하게 하지 않고 메모리 보관 안내를 표시한다.

복원 여부를 선택하기 전에는 기존 보관본을 새 입력으로 덮어쓰지 않는다. 이때는 복구 선택 화면이 입력 화면을 대신한다. 공용 PC에서는 사용을 마친 뒤 로그아웃하도록 복구 화면에 안내한다. 보관 기간·인증·권한 검증은 변경하지 않았다.
