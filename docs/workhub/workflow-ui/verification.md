# 입력 화면 정리 자동 검증

## 검증 범위

- 실제 React 컴포넌트, 전송 어댑터, 응답 검증과 합성 학교·교사·DB·Storage 응답을 사용했다.
- 운영 DB·실제 회원·유료 AI를 호출하지 않는다. 외부 요청은 브라우저 시험에서 차단한다.
- 기존 수신자 확인, 파일 검사, 초안·공개·최종 제출 구분, 요청 번호 재확인, 권한 회수, 이동 잠금의 회귀를 포함한다.

## 결과

최종 수정본을 기준으로 확인한다. 브라우저 검사는 전체 npm test와 별도로 집계한다.

| 검사 | 결과 |
| --- | --- |
| 전체 `npm test` | 5,204건 통과 · Python 생략 없음 |
| `npm run check:workhub` | 통과 |
| `npm run build` | 통과 |
| `npm run build:workhub` | 통과 |
| `npm run check:workhub:design` | 통과 |
| 관련 브라우저 회귀 16개 파일 | 전부 통과 · 209개 시나리오 |

새 `workhub-workflow-ui.mjs`는 다음 5가지를 검증한다.

1. 메시지 두 열 배치·소속 상세·390px 전환에서 입력과 대상을 보존하고, 최종 확인 전 전송하지 않는다.
2. 내 업무 제목·기한·메모를 원래 명령에 그대로 전달한다.
3. 수합 대상 검색 후에도 선택을 보존하고, 파일 선택만으로 업로드하지 않으며 저장 결과는 초안이다.
4. 추가 질문이 있는 초안을 다시 열면 질문 설정을 펼쳐 보여 준다.
5. 320px·큰 글씨·어두운 화면에서도 입력과 버튼이 가로로 잘리지 않는다.

## 발견과 보완

- 추가 질문의 펼침 상태를 입력 내용에 직접 묶으면 마지막 질문을 비울 때 영역이 접혔다. 펼침 상태를 분리했고, 기존 HWPX 시험의 글 질문 삭제→숫자 질문 입력 회귀가 다시 통과했다.
- 최초 전체 시험에서 변경하지 않은 CP-SAT 시험이 제한 시간 내 해를 얻지 못했다. 단독 재실행에서도 완전열거 대조 일부에서 `unknown`이 발생했다. 기대값이나 제한 시간을 바꾸지 않았다. 브라우저 실행을 마친 뒤 순차 실행한 전체 시험에서 CP-SAT 29건이 통과했다.
- 기존 SSR 시험의 번호형 제목 기대값을 새 제목과 내용→대상→양식 순서 검사로 갱신했다. 파일 선택·비공개 안내·초기 선택 설정 접힘 검사는 유지했다.
- 신규 화면 시험의 합성 서버에 내 업무 저장 응답이 빠져 있었고 실제 메뉴·수정 버튼 이름이 달랐다. fixture와 탐색 경로를 고쳤다. 앱의 저장 조건이나 계약은 바꾸지 않았다.

운영 확인은 사용자 요청대로 나중에 진행한다. 캡처의 파일 업로드·저장 성공은 합성 서버 기준이다.
