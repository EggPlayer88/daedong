# 문서 계열 스킨 보완

2026-10-16. 문서함·질문형 수합·학교자료 HWPX 가져오기 화면의 표시만 보완했다. DB·전송 계약·인증·문서 생성·공개 범위는 바꾸지 않았다.

## 확인한 문제와 수정

차콜 스킨을 선택해도 문서 카드가 흰색으로 남고 일부 제목·설명의 대비가 낮아졌다. 실제 `WorkspaceShell`과 `DocumentsWorkspace`로 재현했으며, 수정 전 브라우저에서 공통 surface는 `rgb(28,36,48)`인데 문서 패널은 `rgb(255,255,255)`였다.

`documents.css`가 공통 셸에 정의되지 않은 `--wh-*`를 사용한 것이 원인이었다. 해당 스타일을 `--ui-*`에 연결했다. 문서 카드·글자·보조 설명·선택 표시·주요 버튼·오류 안내·초점을 함께 맞췄다. 차콜의 주요 버튼 글자는 밝은 강조색 위에 어두운 전경색을 사용한다. 문서함·질문형과 학교자료 가져오기는 같은 스타일을 재사용한다.

공통 간격 설정을 카드 여백에 반영했다. 좁은 화면에서는 목록/본문/비교/입력 열을 한 열로 표시하고, 긴 제목·원문 위치·질문은 줄바꿈한다. 글자를 키워도 입력·버튼이 화면 밖으로 밀리지 않게 최소 너비와 줄바꿈을 조정했다.

공통 `workspace-shell.css`, `appearance/theme.css`와 기능 코드에는 변경이 없다. 셸 밖의 단독 화면에도 기존처럼 기본 색상은 제공한다.

## 검증

- 새 `tests/browser/workhub-document-appearance.mjs`: **22개 시나리오 통과**.
  - 실제 문서함·질문형·학교자료 가져오기 × 화이트/웜/차콜.
  - 카드·본문·주요 버튼·보조 설명·오류 안내의 색상 연결 및 대비 확인. 활성 본문/주요 버튼/오류 조합은 4.5:1 이상이며, 비활성 컨트롤을 이 수치에 포함하지 않는다.
  - 실제 화면 설정에서 스킨·간격·큰 글자 변경 뒤 입력 유지, 설정 닫기 초점 복귀와 키보드 초점 표시.
  - 320px 화면에서 글자 크기 변수를 기본의 200%로 확대하는 합성 환경: 가로 넘침 없음, 주요 조작이 화면 안에 있음. 브라우저 고유의 텍스트 확대 설정 전체를 대체하지 않는다.
- 기존 전용 단위 시험: 문서 **25**, 학교자료 가져오기 **17**, 화면 설정 **19** 통과.
- 기존 브라우저: 문서/질문형 **13**, 학교자료 가져오기 **8** 통과.
- 수정 전후 실제 화면 스크린샷을 확인했다. 저장소에는 시험 코드만 넣고 합성 화면과 결과 JSON은 로컬 QA 폴더에 남겼다.

합성 서비스로 실제 React 화면을 실행한 시험이다. 운영 Supabase·Storage·한글 파일의 인쇄·교사 실사용 결과는 포함하지 않는다.

## 판단해서 정한 것

- 전역 변수 별칭을 추가하는 대신 문서 계열 CSS에서 공통 스킨을 직접 사용했다. 다른 모듈의 색을 바꾸지 않으면서 세 화면을 함께 고칠 수 있기 때문이다. 변경 범위는 `apps/workhub/src/documents/documents.css`다.
- 기능·저장 로직이 바뀌지 않아 구현을 그대로 따라 하는 새 단위 검사는 추가하지 않았다. 기존 문서/자료/설정 단위 검사와 실제 브라우저의 스타일·키보드·반응형 회귀를 사용했다.
