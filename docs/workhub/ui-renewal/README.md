## 기능과 계약의 경계

DB·SQL·서버 API·인증·공개 범위·AI 모델과 비용 설정은 바꾸지 않는다. 메뉴는 기존 `enabledModules()` 결과만 재배치한다. 기존 평가계획서 메뉴와 양식은 그대로다.

AI 패널을 여는 행동은 질문 전송이나 업무 저장이 아니다. 현재 화면의 내용은 자동으로 AI에 전달하지 않는다. 각 기능의 ‘도움 받기’가 전달한 명시적 근거만 기존 계약으로 사용한다. 실제 전송·제출·시간표 확정은 종전의 검토·동의 절차가 필요하다.

업무 편집 중에도 AI 옆자리를 열 수 있지만, 다른 업무로 이동하는 기존 잠금은 유지한다. AI 입력이나 미확정 요청이 있으면 패널을 닫아도 그 상태를 알리고 다시 열 수 있다. 학교·소속 범위가 바뀌면 이전 학교의 숨은 AI 화면도 다시 표시하지 않는다.

## 검증과 화면

검증 기록은 [verification.md](verification.md)에 정리한다. 화면 캡처는 실제 React·전송 어댑터·응답 parser에 합성 자료를 넣어 촬영한 것으로, 운영 DB 시험 자료를 생성하지 않는다.

배포는 사용자가 PR을 병합한 후 Vercel Production에서 확인한다. 이 변경에 필요한 추가 SQL·환경변수는 없다. 실제 교사 연결과 공개 범위를 확대하지 않는다.
