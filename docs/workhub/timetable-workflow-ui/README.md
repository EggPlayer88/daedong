프리텐다드·기존 스킨 변수를 그대로 사용한다. 새 아이콘 라이브러리나 폰트를 추가하지 않았다. 서버·DB·인증·비용·권한·메뉴 공개 범위는 변경하지 않았다.

## 판단해서 정한 것

1. **준비 현황은 편성 가능 판정이 아니다.** 기존 누락 점검 결과를 요약했으며 ‘기본 입력 채움’으로 표시한다. 시간 충돌·서버 검사를 통과했다는 표시를 만들지 않는다.
2. **단계를 새 마법사로 나누지 않는다.** 기존 입력을 유지한 채 필요한 항목으로 초점을 이동한다. 화면 이동 자체는 저장·계산·전송을 호출하지 않는다.
3. **교환함을 새 양식보다 먼저 배치한다.** 교사는 자신에게 온 동의 요청을, 담당자는 승인할 요청을 먼저 찾는다. ‘새 요청 작성’으로 양식에 바로 이동할 수 있고, 왕복해도 작성한 선택과 사유는 그대로다.
4. **오류와 확인 절차를 접지 않는다.** 접는 것은 조건 의미·점수 해석·추천 안내다. 충돌·원본 변경·결과 미상 복구·최종 동의 체크는 기존처럼 확인할 수 있다. 승인할 요청을 선택하면 변경 전후가 펼쳐진다.
5. **목록 검색은 실제 승인 대상을 바꾸지 않는다.** 필터 밖의 확인 중인 요청을 유지하는 기존 동작을 그대로 둔다. 완료한 요청이 ‘내 승인’에서 사라지면 전체 목록에서 완료 상태를 볼 수 있다.
6. **작은 화면에서 입력을 다시 만들지 않는다.** CSS로만 배치를 바꾸고, 키보드 이동·320px·큰 글씨·어두운 스킨을 검증한다.

되돌릴 때는 이번 PR의 시간표 TSX 6개와 `timetable-workflow-ui.css`를 되돌린다. 서버 함수·SQL·운영 데이터는 되돌릴 대상이 없다.
