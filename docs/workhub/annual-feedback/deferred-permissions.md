# 권한 확대 보류 항목 — 설계만 준비

2026-10-29 사용자 결정에 따라 아래 세 기능은 **구현·SQL·권한 부여·메뉴 공개를 하지 않는다.** 현재 가능한 담당자/당사자 기능만 유지한다.

| 후속 후보 | 제안할 명령·검증 | 반드시 제외할 것 | 구현 전 결정 |
|---|---|---|---|
| 관리자 대리 인계 | 현재 공식 담당·원본 판·수신 교사 소속을 먼저 조회 → 대리 사유와 대상 미리보기 → 관리자 확인 → 받는 교사 수락. 같은 요청 번호 원장, 이전/이후 담당·처리자 감사 기록 | 개인 상담·메시지·개인 기억·학생 사적 기록, 수신자의 수락 생략, 관리자 자기 승인 | 대리 사유 범위, 확인 담당자, 기존 담당자에게 알릴 조건 |
| 학교 전체 수합 조회 | 학교 범위의 수합 개수·상태·담당자 요약. 파일 열람과 제출물 다운로드는 별도 권한으로 분리. 페이지·필터·학교 및 판 검증 | ‘전체 현황 조회’가 곧 제출 원문·파일 접근권이 되는 것 | 관리자에게 공개할 메타데이터, 참여자 이름·미제출자 노출 범위 |
| 일반 교사 양식 제작 | 개인 초안 제작·시험 생성 → 담당자 검토 요청 → 기존 게시 권한자가 대상·매핑·샘플 검증 후 게시 | 교사 초안의 자동 학교 게시, 임의 수합 공개, AI 자동 실행·추가 비용 | 개인 초안 보관/공유 범위, 게시 확인 책임자 |

현재 AF1 인계 알림 이동은 기존 당사자 조회 권한을 사용한다. 화면에 도착해도 자동 수락·대리 승인하지 않는다. 일반 교사의 해당 업무 참여 범위는 기존 시범 허용 목록 그대로다.

함께 보류: 초기 인증 연결 최적화는 동시 프로필 조회 공유·INITIAL_SESSION 처리의 구체적 승인을 요청한 상태이며, 이번 구현에서 인증 코드는 변경하지 않았다. 승인되면 오래된 프로필 캐시를 두지 않고 로그아웃·계정 변경·승인 철회·저장 전후 검증 회귀와 함께 별도 반영한다.
