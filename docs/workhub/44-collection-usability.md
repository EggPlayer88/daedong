# 문서 수합 화면·사용성 후속 보완

2026-10-16 · `feat/workhub-collection-usability` · 기준 PR #45 `2f8d9a3`

## 교사가 보는 변화

- 새 수합, 상세, 초안 수정, 제출 작성, 관리·검토를 열면 해당 제목과 입력 영역으로 이동한다. 취소/닫기/목록 복귀 시 원래 진입 버튼으로 돌아온다.
- 제출 준비를 작성 → 초안 저장 → 최종 제출로 표시한다. 현재 필요한 행동을 먼저 보여 주고 추가 조건은 접어서 제공한다. 파일 추가와 초안 저장을 최종 제출로 표시하지 않는다.
- 저장본과 현재 입력이 같은지, 필수 파일·글·숫자(0 포함), 책임 교사, 재제출 사유와 보완 선택 조건을 같은 계산으로 안내하고 최종 제출 버튼에 반영한다. 권한·기한·파일/버전의 최종 판정은 기존 서버다.
- 파일 선택기에 HWPX·크기·첨부 개수와 한도 도달 이유를 연결한다. 긴 파일명을 내려받기 버튼에 중복 표시하지 않되 스크린리더 이름은 보존한다.
- 접수가 확인된 뒤 초안 저장/최종 제출/공개/검토/철회/정정 결과를 구분하고 한국 표준시로 접수 시각을 표시한다.
- 배경 재조회로 입력이 잠시 사라질 때 메모·커서 선택 범위를 복원한다. 기다리는 동안 사용자가 다른 곳으로 초점을 옮겼다면 그 선택을 유지한다. 일반 DOM과 업무실 ShadowRoot 모두 확인했다.

## 범위와 보존

앱 화면·표시용 계산·CSS·시험만 바꿨다. DB SQL, RPC 계약, Vercel API, 인증·회원, 파일 검사, 서버 환경값, 메뉴 공개 범위는 변경하지 않았다. PR #45를 검토하는 동안 그 브랜치에는 새 커밋을 추가하지 않고 후속 브랜치에서 작업했다.

기존 파일/입력/요청 번호 보존과 서버 권한 재확인·충돌 복구를 유지한다. 실사용 확인은 이후 모아서 진행하며 운영 Supabase에는 접속하거나 SQL을 적용하지 않았다. R1S SQL 작성·적용, 서버 환경값·학교별 활성화가 여전히 필요하다.
