# 수합 생성과 양식 저장 개선

새 수합을 만들 때 양식 파일까지 고르고 `수합 초안 저장`을 한 번 누른다. 제목·기한 → 양식 → 제출 대상으로 화면을 나누고, 검토자와 글·숫자 질문은 선택 설정으로 접었다. 수정 화면에서는 상세 화면을 함께 반복하지 않는다. 기존에 저장된 파일은 편집 중에도 내려받을 수 있다.

## 사용 순서

1. 문서 수합 → 새 수합 만들기.
2. 제목·기한·안내, HWPX 양식, 제출 대상을 입력한다. 양식은 여러 개 선택할 수 있고 저장 전 선택 취소도 가능하다.
3. 수합 초안 저장. 기존 서버의 초안 생성 → 파일 예약·Storage 업로드·HWPX 확인 → 양식 연결 저장을 화면에서 이어 처리한다.
4. 완료된 초안을 확인한 뒤 `대상 교사에게 공개`를 별도로 누른다.

파일을 선택하기만 하면 서버에는 쓰지 않는다. 화면의 파일당 크기와 개수는 학교의 기존 파일 정책에서 읽는다. HWPX 내용 검사, 해시 확인, 접근 권한과 공개 범위는 기존 경로를 사용한다.

## 판단해서 정한 것

- 한 번 누르는 저장은 여러 기존 서버 명령을 이어 실행하는 방식이다. DB와 파일 저장소를 하나의 원자적 트랜잭션으로 바꾸지 않았다. 중간에 실패하면 이미 만들어진 비공개 초안이 남고 같은 초안으로 이어간다. 새 SQL 실행은 필요 없다.
- 초안 생성·최종 연결 저장의 결과가 불명확하면 원래 명령과 요청 번호를 보존한다. 파일 예약·완료도 원래 번호를 재사용한다. 자동으로 새 번호를 발급해 다시 실행하지 않는다.
- 일부 파일이 거부되면 이미 확인된 파일과 작성 내용을 유지한다. 거부된 선택을 해제하고 교체한 뒤 저장한다. 검사 대기 취소도 해당 선택만 해제하며 서버 파일을 삭제하지 않는다.
- 생성 접수 뒤 조회된 초안 판이 달라지면 자동 진행을 멈추고 비교한다. 최종 연결 저장도 기존 판 충돌 확인을 거친다.
- 이전 렌더의 자동 처리 효과가 뒤늦게 실행되면 현재 편집 상태와 비교해 중복 실행을 막는다.
- 선택 파일과 미저장 입력은 기존 탭 메모리에 보관한다. 새로고침·브라우저 종료 후 파일 복구를 보장하지 않으며, 기존 이탈 경고를 유지한다.
- 되돌리려면 이 PR의 수합 화면·선택 도우미·스타일 변경을 되돌리는 PR을 만든다. SQL·저장 자료를 되돌릴 필요는 없다.

## 검증 범위

- `tests/test_workhub_collection_template_staging.mjs`: 파일 크기·확장자·개수 합산, 묶음 선택 오류 시 기존 파일 보존, SSR 화면 구조.
- `tests/browser/workhub-collection-create.mjs`: 실제 React 화면과 합성 서버로 한 번 저장, 파일/생성/연결 응답 유실, 검사 거부·대기·취소, 재진입·계정 변경, 판 충돌, 조회 복구, 좁은 화면을 확인한다.
- 기존 수합 생성·공개·제출·보완·정정·ZIP·접근성 브라우저 회귀도 함께 실행한다.
- 브라우저 시험은 가상 교사를 사용하고 DB·Storage 응답은 합성이다. 실제 Supabase 업로드 성공을 증명하는 결과로 해석하지 않는다. 운영 연결 확인은 배포 후 사용자가 이어간다.

검증 숫자는 PR 설명과 최종 검증 기록을 따른다. 운영 DB 변경, 실제 회원 연결, 자동 병합은 하지 않았다.

## 창 복귀 시 화면 유지

알트탭·다른 탭에서 돌아올 때 신원과 학교 소속을 다시 확인하고 목록도 최신화한다. 이전에는 이 조회마다 수합 상세·작성 폼과 홈 목록을 지워 화면이 번쩍였고, 같은 계정의 토큰 갱신이 겹치면 취소된 조회를 연결 오류로 표시했다.

- 같은 학교·같은 자료를 확인 중일 때 수합 상세·입력·선택 파일·커서·스크롤, 홈 일정·업무·시간표 요약을 유지한다. 저장·공개는 조회 완료 뒤에 할 수 있다.
- 실제 조회 실패·접근 거부에서는 이전 결과를 숨기고 기존 복구 경로를 사용한다. 다른 학교·다른 수합·다른 날짜에는 앞선 결과를 표시하지 않는다.
- 포커스 조회와 동일 계정 세션 갱신이 겹친 취소는 최신 조회로 이어간다. 실제 계정·권한 무효화 구독과 인증 서버 코드는 변경하지 않았다.
- 지연 응답과 세션 갱신 경합을 합성 브라우저에서 재현했다. 수정 전 상세 DOM 제거와 중간 연결 오류가 실패하는 것을 확인하고 같은 회귀로 고정했다.

되돌릴 때는 화면 유지 변경 커밋을 별도로 되돌리면 된다. 서버 인증 재검증·DB·환경변수 변경은 없다.
