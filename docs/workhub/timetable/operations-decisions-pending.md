# 사용자 결정과 구현 담당 분리

2026-10-19 · 이번 앱 작업으로 아래 결정을 확정하지 않았다.

| 항목 | 이미 적용한 방향 | 결정 또는 다음 작업 |
|---|---|---|
| 시간표 제안 AI | Claude 사용, 사람 확인 후 반영 | C7 비용 통제 코드/SQL, 모델·입출력 한도·학교 예산·실패 과금·결과 미상 정산 주체/주기·보관 기간(D1~D10) 별도 결정 |
| 일반 교사 공개 | superadmin 제한 유지 | 모듈 설치/배포 확인 후 사용자 활성화·공개 승인 |
| 대강 담당 | 이동·교환 계약으로 담당자를 바꾸지 않음 | 대강 자격·승인·실제 담당 관계·학생자료 범위 검토. 기본 제안은 시간표 담당자 최종 승인, 해당 수업에 한정. 확정 아님 |
| 보강 | 미실시/확인 필요를 별도 기록 | 원수업 연결·보강 시수·추가 시각·중복 집계 방지 계약 필요. AI가 임의로 시수 충족 선언하지 않음 |
| 실시 기록 | 서버가 허용한 결과만 입력 | 기존 담당 관계 적용은 Claude가 검토. 대리 기록 등 새 권한은 별도 결정 |
| 운영 자동화 | 별도 검사기·자동정리·예약운영 보류 유지 | 필요할 때 비용/운영 책임과 함께 별도 승인 |

지금 바로 결정을 받아야만 진행 가능한 앱 작업은 완료하고, 위 항목 때문에 기존 구현을 임의 변경하지 않는다. SQL은 Claude와 사용자가 적용한다. 이번에 사용자 대신 새 예산·AI 모델·권한을 정하지 않았다.
