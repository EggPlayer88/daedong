# 시간표 편성 사용성 보완 — 2026-10-17

PR #65의 후속 작업이다. 학교 담당자가 `기초 자료 준비 → 조건 확인 → 계산 → 비교·조정 → 저장·확정 검토`를 이어가는 데 필요한 기능을 묶었다. DB 계약·SQL·회원·인증·비용·메뉴 공개 범위는 변경하지 않는다.

## 1. 반복 입력 줄이기

- 기존 시간대의 이름·시작·종료를 편집한다. ID·요일·차시 수는 유지하며, 이 시간대를 허용한 수업 활동과 실제 시각 변화가 미리보기에 나온다.
- 한 요일의 선택 시간대를 여러 요일로 복사한다. 정확히 같은 시간대는 건너뛴다. 같은 이름·차시에 서로 다른 시각이 있으면 먼저 확인하도록 막는다. 학년별 이름이 다른 중첩 시간대는 합치지 않고 안내한다.
- 복사만으로 기존 수업의 허용 목록을 넓히지 않는다. 새 시간대 허용은 담당자가 따로 선택한다.
- 선택한 여러 수업을 1차시 활동으로 구성한다. 기본값은 기존 활동 보존이다. 대체를 명시적으로 선택하면 기존 연속수업·활동 ID·허용 목록이 바뀐다는 사실을 보여 준다.
- 기준 시수가 없거나 기존 활동과 시수가 다르면 일괄 작업을 부분 적용하지 않는다. 공식 시수·교사·수강 집단을 이 도구로 수정하지 않는다.
- 미리보기 뒤 자료가 바뀌면 다시 검토한다. 같은 미리보기의 ID를 재사용하고, 저장되지 않은 입력은 현재 탭의 기존 복구 범위에 보관한다.

관련 구현: `preparation-editing.ts`, `PreparationEditingTools.tsx`, `TimetablePreparationPanel.tsx`.

## 2. 계산 전에 설명 가능한 충돌 알리기

- 고정 수업이 실제 시각상 자원 수용 한도를 넘는 경우.
- 고정/허용 시간 전부가 참여자·자원의 불가 시간과 겹치는 경우.
- 필요한 시수가 실제 시간 겹침을 반영한 배치 가능 상한보다 많은 경우.

교시 이름이나 ID가 달라도 실제 시각으로 검사하고, 수용량이 2인 공간에 수업 2개가 겹친다는 이유로 막지 않는다. 관련 수업·교사·학급·시간과 수정할 위치를 설명한다. 조건을 자동으로 완화하지 않는다.

**충돌을 찾지 못했다는 결과는 ‘아직 미판정’이다.** 모든 필수조건의 해가 존재한다거나 최적 시간표라는 뜻이 아니다. 미지원 조건과 잘못된 자료도 불가능한 시간표로 단정하지 않는다. 실제 계산 결과는 독립 배치 검증기를 다시 통과해야 한다.

일반 계산과 최적화 파일 요청 모두 작업 고정을 포함한 실제 계산 기준으로 검사한다.

관련 구현: `preflight.ts`, `TimetablePreflightPanel.tsx`, `FoundationPanel.tsx`.

## 3. 완성표와 미완성표 조정

- 한 수업 이동 외에 두 수업의 자리를 함께 맞바꾼다. 각각 이동하면 충돌하는 경우도 최종 두 수업 배치 전체를 검사한다.
- 공식/초안 필수 고정과 작업 고정을 유지한다. 허용 시간·연속 차시·교사·학급·공간 수용량을 다시 검사한다.
- 변경 전후를 확인하고 누르면 부모 작업창이 최신 기준으로 다시 검증한 뒤 한 번에 반영한다.
- 교환 후보는 검사 범위와 한도를 표시한다. 일부 후보가 없다는 결과를 학교 전체에 교환 가능성이 없다는 의미로 사용하지 않는다.
- 엑셀에서 가져온 미배정 수업은 목록에서 선택하여 이어 배치한다. 현재 배정된 수업의 충돌 검사와 모든 수업이 끝난 최종 검사를 구분한다. 미배정이 남으면 서버 저장·확정 검사를 통과한 것으로 표시하지 않는다.
- 직전 배치로 되돌리는 경우에도 현재 고정을 검사한다. 실제 학기 수업 교환의 동의·승인 절차와 편성 초안의 맞바꾸기는 별개다.

관련 구현: `adjustments.ts`, `TimetableAdjustmentPanel.tsx`, `TimetableWorkspace.tsx`.

## 4. 채택 전에 후보를 읽기

- 기존 작업 배치 또는 다른 계산 후보와 수업별 변경 전후를 비교한다.
- 이동·교사/학생집단/교과/차시 배정 변경·추가·제외를 구별한다. 한 수업이 이동과 배정 변경에 함께 포함될 수 있다.
- 수업 ID로 연결하고 실제 시각과 참여자를 비교한다. 이름·교시 ID·배열 순서만 바뀌었다고 이동으로 세지 않는다. 이전 배정은 당시 기준판으로 표시한다.
- 교사·학급·수강 집단·공간을 검색하고 요일별 배치를 읽는다. 많은 변경과 하루 목록은 쪽을 나누며 전체 건수를 유지한다.
- 비교만으로 작업 배치를 바꾸지 않는다. 후보를 바꾸면 기존 채택 확인을 해제한다. 입력·기준판이 달라진 결과는 기존 지문 검사에 따라 사용할 수 없다.

관련 구현: `candidate-review.ts`, `TimetableCandidateReview.tsx`, `TimetableEnginePanel.tsx`.

## 판단해서 정한 것

1. 서버 없는 상태에서 유용한 편성 기능을 우선 보완했다. CP-SAT는 여전히 로컬 CLI 파일 왕복이며 계산 서버가 배포된 것처럼 표시하지 않는다.
2. 기존 수업과 허용 목록 보존을 일괄 편집의 기본으로 삼았다. 대체가 필요하면 같은 도구의 명시적인 대체 모드로 바꿀 수 있다.
3. 사전 진단은 증명할 수 있는 필요조건 위반만 다룬다. 새 진단을 추가할 때에는 작은 완전탐색/독립 검증과 대조해 잘못 막는 경우부터 검사한다.
4. UI 확장은 기존 준비·편성 패널 안에 접을 수 있는 도구로 배치했다. 새로운 상위 메뉴를 만들지 않는다.

## Claude 검토 범위

기존 시간표 검토 요청에 이번 문서를 추가한다. 특히 미리보기 원본 변경, 명시 대체와 안정 ID, 중복 일과, 미배정 검증의 충돌 누락, 부분 검사 한도의 설명, 수용량 2 이상·실제 시각 경계, 고정 보호와 되돌리기, 비교의 이전 판 보존을 확인한다.

추가 SQL은 요청하지 않는다. 기존 T1/T2 계약의 서버 검증과 원자적 저장은 계속 필요하며 앱 검사만으로 이를 대신하지 않는다. 실제 학교 DB/Claude/교사 PC 확인은 기존 계획대로 나중에 모아서 진행한다.
