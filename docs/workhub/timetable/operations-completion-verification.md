## 최초 실패와 수정

- 공유 보드: 상위에서 새 수업 ID가 전달될 때 선택 state가 초기값만 사용하던 회귀를 고쳤다. 외부 새 연결은 입력 잠금이 풀린 뒤 반영한다.
- 보드 사용성: 일반 처리 잠금에서 읽기용 수업 상세까지 막는 회귀를 고쳤다. 실시 기록 편집의 선택 잠금과 일반 쓰기 잠금을 분리했다.
- 대상 학기: 오류 callback/alert가 먼저 보이고 React가 이전 select를 제거하기 전 개수를 세던 시험 경쟁을 고쳤다. 오류 상태와 이전 목록의 실제 비노출을 모두 기다린다. 기대값을 완화하지 않았다.
- 독립 검토: 같은 요청 번호의 최초 실시 기록 원장 ID/기록 시각이 바뀌는 응답을 허용하던 점을 고쳤다. 운영 접수증에도 같은 불변 대조를 보강했다.

## 실제로 검증하지 않은 것

브라우저는 실제 React·전송 어댑터를 사용하지만 DB/Storage/Claude 응답은 합성이다. 일부 기존 계산 시험은 실제 Python/CP-SAT/로컬 파일/브라우저 Worker를 실행한다. 이번 결과를 실제 Supabase T2 왕복, 실제 서버의 원키 동시성, SQL 권한, 학교 데이터 보존, 운영 모듈 활성화 성공으로 읽으면 안 된다. 새 실시 기록 RPC의 exact 계약은 아직 Claude가 SQL로 구현·대조해야 한다.

GitHub CI 결과는 최종 PR head에서 별도로 확인한다. 자동 테스트 통과는 교사 공개 승인과 다르다.
