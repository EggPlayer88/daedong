# Claude 검토 요청 — 시간표 편성 기반

2026-10-16 · 브랜치 `feat/workhub-timetable` · 기준 PR #48 `5f3d40f`

시간표 보류를 해제한 사용자 요청에 따라 편성 계산·독립 검증·담당자 화면과 연결 계약을 별도 브랜치에 구축했습니다. 검토 중인 #48의 커밋과 기존 SQL을 바꾸지 않았습니다. 현재 진행 중인 학교/일정/메시지/학생/비서 등 1~7단계 SQL은 계속 진행하고, 시간표는 **후속 8단계**로 검토해 주세요.

## 이번 검토의 대상

- [전체 설계](README.md): 기초 자료→조건→편성→수동 조정→초안 저장→공개→날짜별 교환의 목표와 실제 구현 구분.
- [운영 설계](operations.md): 확정판·날짜별 수업·교환 동의·승인·이력의 후속 구현 명세.
- [SQL·AI 연결 요청](sql-handoff.md): 현재 앱 3개 RPC와 아직 구현하지 않은 공개/교환 API의 경계.
- [검증 결과](verification.md): 합성 서버·실제 Worker·독립 열거 대조, 실제 환경 미검증 범위.

## 우선 확인할 것

1. **편성의 정확성**: 시수 누락/초과, 교사·학급·선택수강 집단·공간 충돌, 서로 다른 일과 시각, 연속 블록, 고정/불가 시간, 자원 용량. 학교급 이름만으로 지원을 보증하지 않고 필요한 조건이 미지원이면 막는지.
2. **결과의 의미**: 계산 한도 초과는 unknown, 탐색 완료 후 해 없음만 infeasible. feasible은 첫 유효 후보이며 최적성을 보증하지 않음. 탐색 결과와 독립 validator가 갈라지면 저장 불가.
3. **교사 화면과 저장 복구**: 계산 중 UI 사용/취소, 조건 변경 후 늦은 결과 무시, 공식 필수조건 보존, 수동 이동/되돌리기, 결과 미상 시 원래 명령·요청 번호 유지. recover-only는 최신 기초판과 무관하게 같은 원장만 조회하고 새 초안을 만들지 않아야 함.
4. **조회 범위**: 일반 교사 canDesign=false이면 basis=null/drafts=[]; lessons는 서버의 실제 본인 수업 관계로 제한. 승인·학교·소속·역할 변경 뒤 이전 자료가 남지 않는지. 현재 메뉴 공개는 superadmin 그대로.
5. **Claude 제안**: 현재 기초판·조건·배치·질문의 지문 고정, 사람 확인, 모호한 질문 미해결 시 거부. 공식 조건 삭제·교사 변경·공개·실제 교환 확정 도구 없음. 실제 provider는 아직 연결하지 않음.
6. **날짜별 교환 도메인**: 허용 목적시간·실제 구간·자원·원본판·당사자 전원 동의·같은 계정 자기승인 차단. 현재는 사전 검증이며 DB 경합/원자성/실제 승인 완료라고 평가하지 않음.
7. **확장성과 보존**: 엔진/독립 검증/UI/어댑터/운영 도메인 분리, 지연 로딩, 미설치 RPC 실패 격리. 기존 PR #5 전체 병합 없이 만든 경계가 후속 CP-SAT 교체에도 적합한지.

## SQL 작업 순서

바로 운영 SQL 실행을 요청하는 문서가 아닙니다. 먼저 1~7단계와 실제 기준자료의 매핑·누락을 정리하고, `sql-handoff.md`의 3개 현재 RPC에 대한 JSON fixture를 앱 parser로 검증해 주세요. 기초판 작성 UI·공개/교환 서버와 화면은 별도 후속 구축이 필요합니다. 그다음 증분 SQL 초안→격리 PG 검증→앱 계약 대조→사용자 직접 적용 순서로 진행합니다. 과거 R0/R1/R1S를 재실행하거나 수정하지 않습니다.

앱 PR은 #48 위에 쌓은 검토용 초안입니다. 먼저 #48 검토/사용자 병합이 끝난 뒤 기반 변경과 차이를 다시 확인합니다. 코드 병합 가능 판단과 실제 시간표 활성화 가능 판단을 별도로 적어 주세요. 자동 병합·일반 교사 공개·SQL 실행·API 키/모델/요금 설정 변경은 하지 않습니다.

## 답변 형식

- 차단 결함: 재현 조건, 파일/함수, 영향, 권장 수정.
- SQL 계약 차이: 누락/불일치 필드, 최신판·잠금·멱등·권한 문제.
- 편성 품질: 반드시 필요한 조건과 이후 최적화 제안을 구분.
- 사용성: 시범 전 필수/후속 개선을 구분.
- 실제 Supabase·Claude·학교 데이터 미검증 범위 유지.
