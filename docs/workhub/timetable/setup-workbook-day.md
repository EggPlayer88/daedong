# 준비 엑셀 기준일 변경 보완(U-1)

## 교사가 보는 변화

어제 내려받아 편집한 공간·수업 연결 엑셀을 오늘 다시 올릴 수 있다. 날짜만 지난 경우에 한하며, 파일 기준일과 현재 기준일을 화면에 알리고 기존 변경 비교와 명시 저장 확인을 다시 거친다. 이미 미리보기를 승인한 상태에서 기준일이 바뀌어도 승인을 자동으로 이어가지 않는다. 보관 파일을 다시 검사한 뒤 확인해야 한다.

## 허용 범위

- 파일의 유효한 과거 기준일 하나를 현재 준비 원본에 대입해 대조용 원본을 재생성한다.
- 학교·학기 ID/이름/기간·sourceRevision·sourceFingerprint·공간과 개별 판·학급·수업·배정 교사·수강 인원·수업 연결과 판·편성 여부·findings는 전부 일치해야 한다.
- 기준 시트와 숨은 원본대조를 함께 확인한다. 메타데이터 한쪽만 수정한 파일, 미래 날짜, 학기 밖 날짜, 잘못된 날짜는 거절한다.
- 미리보기의 sourceKey는 현재 기준일을 포함한 현재 원본을 사용한다. 저장 명령도 현재 개별 판을 기준으로 기존 서버 검증을 거친다.
- 원본대조는 전자서명이나 인증 수단이 아니다. 원본 비교와 별개로 서버가 기존 권한·판·요청 번호를 검증한다.

## 실제 SQL과의 대조

기존 T1-01의 t1_build 반환은 core를 해시한 fingerprint와 별도의 refDay로 구성된다. core는 학교·학기·기간·resources·courses·unsupportedFeatures이며 refDay 자체는 포함하지 않는다. T1-03 setup_get은 refDay를 referenceDay로 별도 반환하고 sourceRevision은 core fingerprint에 연결한다. 따라서 실제 자료에 변화 없이 자정만 지난 경로가 있다. 반대로 날짜 경계에서 교사 배정·수강 관계·편성 수업 등이 달라지면 자료나 지문이 달라지므로 이번 예외가 적용되지 않는다. SQL은 변경하거나 실행하지 않았다.

## 판단해서 정한 것

기준일을 sourceKey에서 빼서 모든 이전 승인을 유지하지 않는다. 파일 재검사에서만 날짜 차이를 한정해 허용하여, 이미 확인한 입력의 원본이 바뀌면 다시 확인하게 한다. 되돌릴 때는 setup-workbook.ts의 referenceDayChange 처리와 배치 패널 안내·재검사 동선을 함께 검토한다.
