## 중요한 회귀

- 공개 적용 마지막 날의 포함/서버 until의 제외 경계를 한 번만 변환한다.
- 초안 판, 입력 기간, 역할, 학교 또는 원본이 바뀌면 기존 미리보기와 확인을 무효화한다.
- 늦은 get/preview/hash 결과가 최신 조회·학교 범위를 되돌리거나 새 쓰기를 시작하지 못한다.
- 이미 시작된 수업, 허용시간 밖 이동, 길이가 맞지 않는 교환, 부분 미리보기, 누락된 참여자/부분 수신증을 거절한다.
- 본인 동의/상대 동의/담당자 승인/실제 반영을 구분하며 같은 계정 자기승인 응답을 거절한다.
- 실행·미확정 결과가 있는 동안 새 쓰기를 막고 원래 명령·요청 번호로 결과만 확인한다.
- 복구 권한 오류는 키를 버리지 않는다. 원장 없음이 확인된 경우에만 입력을 유지한 채 새 검토로 돌아간다.
- 동의·승인 action 복구 성공 뒤 별도 새 요청의 수업·상대·사유가 그대로 남는다.
- 만료된 요청은 동의·승인뿐 아니라 거절·철회·반려도 새 명령을 보내지 않는다.
- 실제 앱 진입 시 미설치 운영 RPC를 준비 완료로 꾸미지 않고, 기존 일정·업무 메뉴를 계속 이용한다.
- 320px 화면에서 가로 넘침 없음, 명시 확인·오류 안내·입력 정리 동작을 검증했다.

## 실행 환경과 증거

Windows의 실제 Chrome·React·앱 전송 어댑터를 사용했다. RPC 응답은 합성 fixture다. 실제 Supabase·PostgREST·운영 DB 잠금·Claude 공급자·메시지 전달은 실행하지 않았다. 시험 중 외부 네트워크 요청·브라우저 오류·민감 입력의 localStorage/sessionStorage 저장이 발생하지 않는지 확인했다.

확정/공유는 320px·1280px, 교환은 320px·1280px 스크린샷을 남겼다. Pretendard 로딩과 모바일 전후 비교를 확인했다. 바탕화면 `GPT작업/2026-10-16_시간표운영/화면`에 사본을 두었다.

최종 서비스 계약은 `operations-contracts.ts`와 `operations-server.ts`가 기준이며 SQL 인계는 [operations-api.md](operations-api.md)다. 실제 서버의 전체 자원 충돌 검사·원자 공개·동의 원장·같은 키 경합·기존 기록 보존은 후속 SQL 검증으로 남는다.

## 변경하지 않은 범위

PR #54 브랜치, Claude SQL 브랜치, `migrations/`, `packages/shared/`, 기존 인증 경로, `apps/main/src/lib/modules.js`, `apps/main/api/`, 확정 HWPX 양식·엔진과 DB 설계 확정본은 이 작업에서 변경하지 않았다. main 병합과 일반 교사 공개도 수행하지 않았다.
