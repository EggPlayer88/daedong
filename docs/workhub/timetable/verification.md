### 전체 브라우저 시험의 후속 확인

첫 전체 실행에서 `workhub-pilot-connected`, `workhub-assistant`, `workhub-mobile-navigation`이 실패했다. 시간표 메뉴를 계속 미구현으로 기대한 값과 복수 제목/경고에 단수 locator를 사용한 문제였다. 기대값을 새 범위에 맞추되 경고의 내용과 실패 격리를 각각 검증한다. 수정 후 연결 셸 7/7, 비서 15/15, 모바일 14/14가 통과했다. 이어 시간표 UI/실제 Worker/연결 셸/비서/모바일/탐색의 6개 파일을 최종 소스로 함께 실행해 전부 통과했다.

추가한 실제 연결 셸 시험은 메뉴 정의에 시간표가 있지만 URL 인식 목록에 빠진 실제 결함을 찾았다. URL 인식 목록을 메뉴 정의에서 만들도록 수정했고, 모드별 허용 목록 제한은 유지했다. 모든 연결 메뉴의 주소 이동과 미리보기의 시간표 차단을 검사하는 회귀를 추가했다.

학교 관리의 셸 제목/내부 제목 중복은 기준 #48에도 존재한다. 이번 시간표는 중복 제목을 만들지 않는다. 학교 관리의 중복 제목 정리는 기존 사용성 후속 항목으로 남긴다.

## 실제로 재현해 고정한 오류 경로

- 반환받은 snapshot을 바꿔 내부 저장 권한·기초판 캐시를 오염시키는 경로: 복사로 격리.
- 비동기 AI 문맥 hash 계산 도중 입력 변경: 진입 시 복사, 현재 문맥 재대조.
- 숫자/한글/공백 ID와 미지 필드의 경로별 느슨한 허용: 공통 ID 규칙과 exact parser.
- 학교 기초판에 들어 있는 필수조건 삭제/완화, 틀린 시수·미지원 조건·자원 누락: 거부.
- 저장 응답 유실 뒤 입력을 고쳐 같은키 재전송, 최신 기초판을 원래 명령에 덮어쓰기: 거부/원래 명령 복구.
- 조회 실패·재마운트·기초판 변경 뒤 원래 요청 확인: recover-only, 새 후보 저장 금지.
- AI 요청문/미추가 조건을 지우고 재생성하거나 저장하는 경로: 입력 보존 및 명시 정리.
- 날짜별 이동의 새벽/다른 일과시간, 학생자원 누락, 오래된 동의·판, 같은 계정의 다른 소속으로 자기 승인: 거부.

## 합성 규모 측정

`scripts/benchmark-workhub-timetable.mjs`에서 교사 30명, 주 30교시의 단순 합성 문제를 실행했다. 6학급/180수업 약 118ms, 12학급/360수업 약 372ms, 24학급/720수업 약 1,102ms에 첫 유효 후보를 얻었고 별도 전체 validator를 통과했다. 단일 로컬 측정이며 재실행 시 시각·기기·부하에 따라 달라진다. 복잡한 선택수업·연강·교사 선호의 실제 학교 성능이나 최적화를 보장하지 않는다.

브라우저 기본 탐색 한도는 1,500ms/50,000노드다. 한도를 넘으면 unknown으로 끝나며 오류나 불가능으로 바꾸지 않는다. 실제 학교 자료로 품질/성능을 측정한 뒤 서버 최적화 연결 필요성을 판단한다.

## 화면 확인

실제 Pretendard 글꼴로 1,280px 및 320px 화면을 확인했다. 320px에서는 표 안에서 가로 이동하며 페이지 자체의 가로 넘침을 막는다. 드래그 없이 수업과 목적 시간을 선택할 수 있다. 스크린샷은 합성 수업 자료의 구성요소 QA이며 로그인된 운영 학교 화면이 아니다.

## 보존과 한계

- 기존 로그인/회원 접근 코드, 모듈의 외부 공개 범위, 확정 SQL, 평가계획 엔진·양식 변경 없음. #48 브랜치 머리도 `5f3d40f` 그대로.
- 실제 Supabase 시간표 RPC/Storage/학교 자료, Claude provider 호출, 실제 승인/공개/교환, DB의 동시성·RLS는 이 시험으로 입증하지 않았다.
- 공개/교환 UI·서버, 학교 기초판 작성, 복합 최적화는 후속 구현이다. 대강/취소/보강은 순수 validator에서도 현재 미지원으로 거부한다.
- 입력 복구는 현재 탭 메모리다. 브라우저 종료 이후 복원은 보장하지 않는다.
- CI는 PR 생성 후 별도로 확인한다. CI의 기존 PG 시험은 시간표 SQL이 실제 설치됐다는 뜻이 아니다.

오류를 완전히 제거했다고 선언하지 않는다. 위 범위의 실패를 차단하고, 미지원·결과 미상·불가능 상태를 구별하는 것을 이번 완료 기준으로 삼았다.
