# AI 답변·근거·개인 기억·관리자 설정 화면 정리

기준 main: `807d7ba` (#91 병합). 작업 브랜치: `feat/workhub-assistant-ui`.

## 교사가 보는 변화

| 화면 | 이번 변경 |
|---|---|
| AI 대화 | 질문·답변을 카드로 구분하고 넓은 화면에서는 예산·대화 목록·개인 기억을 오른쪽에 배치. 좁은 AI 옆자리에서는 질문부터 같은 순서로 표시 |
| 근거 인용 | 자료 제목·판·인용 줄바꿈·원문 버튼을 함께 표시. 자료 식별 번호 등 기술 정보는 필요할 때 펼쳐 확인 |
| 정밀 검토 | 답변 아래에 실행 버튼과 추가 비용 안내를 함께 표시. 직접 누른 경우에만 기존 Sonnet 요청 실행 |
| 개인 기억 | 검색 결과 수·사용 가능/중지/만료·종류·판을 카드로 표시. 수정·중지·삭제 버튼은 짧게 표시하되 접근성 이름에는 대상 제목 유지 |
| 학교 AI 설정 | 월 예산·확정 사용·예약·잔액, Haiku/Sonnet 구분, 키 등록 상태를 먼저 표시. 등록된 키의 교체 입력은 버튼으로 열기 |
| 관리자 운영 현황 | 사용량·예약 주의·요청 상태·서버 진단을 나누고 상태 배지와 간격을 통일. 긴 사용량 표는 내부 스크롤 |

미확정 요청·복구 버튼·오류·추가 비용·예약 주의는 접어 숨기지 않는다. 키 교체 입력이 있거나 요청 결과를 기다리는 동안에는 입력 영역을 접을 수 없다. 키 저장 결과 복구는 입력 영역 바깥에 남는다.

## 유지한 범위

- DB·SQL·RPC·API·권한·인증·공개 범위·실제 교사 연결 변경 없음.
- Haiku 기본/Sonnet 정밀 검토, 학교별 예산, 토큰·단가·과금·캐싱·파일 생성 방식 변경 없음.
- 원문 열기는 인용 당시 ID와 판을 전달. 화면에서 새 판으로 바꾸지 않음.
- 기억은 선택·내용 확인·질문에 넣기·AI 실행을 기존 명시 조작으로 유지. 자동 삽입·자동 요청 없음.
- 입력 보존, 계정·학교 전환 시 비노출, 같은 요청 번호 복구, 키 전송 직후 지우기 유지.
- 기존 프리텐다드·공통 스킨·글자 크기·간격 설정 사용. 아이콘 자산 변경 없음.

## 판단해서 정한 것

1. 대화 입력을 화면과 키보드 이동에서 먼저 두고, 850px 이상에서만 도구를 옆으로 나눈다.
2. 인용 자료의 제목·판·본문 위치는 바로 읽고, 기술 식별 번호만 선택적으로 펼친다.
3. 키를 이미 등록한 학교에서 교체 입력을 접어 시작한다. 미등록 학교의 첫 키 입력과 미확정 결과 복구는 바로 보인다.

## 병합 전 확인과 배포

1. 답변의 자료 제목·판·원문 버튼, 넓은 화면과 좁은 AI 옆자리의 순서 확인.
2. 개인 기억 선택 후 내용 확인 전에는 질문에 넣을 수 없는지 확인.
3. 관리자 키 교체를 열고 입력을 지운 뒤 접을 수 있는지 확인. 실제 키 저장은 필요 없음.
4. 어두운/따뜻한 스킨, 큰 글씨에서 상태와 버튼 확인.
5. PR 자동 검사·미리보기 통과 후 사용자가 merge commit으로 병합하고 Vercel Production 확인.

추가 SQL·환경변수·AI 정책 변경은 없다. [자동 검증과 실서비스 경계](verification.md).

## 남은 개선 후보

주요 기능 화면의 정리 이후에는 공통 메뉴·검색·알림·모바일 이동과 빈 상태/오류/복구 안내를 전체 화면 기준으로 최종 점검할 수 있다. 새로운 기능이나 권한 확대와는 분리한다. 실제 교사 연결과 실사용 피드백은 계속 별도 단계다.
