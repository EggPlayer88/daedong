설계를 실제 서비스로 옮기는 순서

01 · 기반 확정

인증 보존·권한·공통 계약

계정과 소속, 정책판, 감사, 명령 계약을 먼저 확정합니다. 기존 회원 대조표와 복구 절차를 준비합니다.

02 · 업무를 끝까지 연결

일정·문서·수합 → 학생 → AI

표만 만드는 단계에서 끝내지 않습니다. 화면에서 생성·접수·정정·검토·출력이 이어지는지 확인합니다.

03 · 적용 전 실증

SQL·동시성·Storage·복원

실제 환경에서 학교 간 격리와 장애 복구를 입증합니다. 시간표 알고리즘 구현은 별도 재개 시 진행합니다.
