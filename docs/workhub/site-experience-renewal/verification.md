## 이번에 발견하고 고친 문제

- 새 메뉴 구성에 맞춰 표시 기대값을 갱신했다. 허용 메뉴 집합·제한 참여 계정의 접근 차단 검사는 유지했다.
- 기존 주 메뉴와 관련 메뉴가 같은 이름을 갖는 경우를 정확히 구분했다. 모바일·접근성·복구·테마 시험의 오래된 메뉴명 선택자를 바꾸고, 키보드 이동·잠금·원번호 복구 기준은 유지했다.
- AI 옆자리의 시작 제안과 보조 도구가 입력·실행 버튼을 첫 화면 아래로 밀던 문제를 고쳤다. 전체 화면은 시작 제안을 제공하고, 옆자리는 질문 입력을 먼저 보여 준다.
- 모바일에서 수업·문서로 이동했을 때 더보기의 현재 위치 표시가 누락되던 문제를 고쳤다.
- 중립 스킨의 작은 보조 글자 대비를 보강했다. 밝음·따뜻함·어두움 테마의 본문·상태 대비 검사를 통과했다.
- 빈 수합을 세 줄로 크게 쌓아 기존 높이 검사가 실패했다. 빈 상태에서만 제목과 전체 보기 버튼을 같은 줄로 배치했다. 높이 제한·44px 버튼·포커스·이동 검사 기준은 완화하지 않았다.
- 수합 외곽 제목과 새로 확인·새 수합 버튼의 중복 행을 줄였다. 768·960·1440px의 큰 글자에서도 제목·버튼·입력 영역이 겹치지 않는지 확인했다.
- 전체 AI 화면에 옆자리의 2열 레이아웃이 남던 우선순위 충돌과 범위 선택 버튼의 불필요한 줄바꿈을 고쳤다. 전체 화면은 본문 영역 중앙에 배치한다.
- Storage 성공 시험의 기본 100ms가 병렬 실행 중 해시 계산을 시간 초과로 오인했다. 단독 재현은 14/14 통과했고, 성공 대기만 1000ms로 고쳤다. 명시적 15ms 시간 초과 시험과 제품 시간 제한은 그대로다. 수정 뒤 전체 기본 시험을 다시 실행해 5,281건 통과를 확인했다.
- 시간표 연습 시험은 전체 실행 중 120초 제한에 도달했다. 같은 제품·시험 코드로 개별 재실행한 결과 15/15 통과, 50.120초였으며 오류·외부 호출은 없었다. 해당 시험의 제한이나 검증 기준을 늘리거나 완화하지 않았다.

## 유지 여부를 확인한 동작

- 작성 중 입력·처리 중 명령·원래 요청 번호의 보존과 복구.
- 서비스 정보의 모달 초점, Escape 닫기, 이전 버튼으로 초점 복귀.
- 모바일 더보기의 수업·학생·문서 접근과 제한 참여 교사의 기존 허용 목록.
- 홈 2×2 구조, 좁은 화면의 같은 읽기 순서, 긴급 업무·오류·미확인 상태 표시.
- 문서 작업의 편집·생성·확정·복사·보관, 질문형 연결 선택과 명시적 확인.
- AI 개인/학교 범위, 근거 인용·판 정보·기억 확인, 추가 정밀 검토·결과 미상 복구.
- 기존 계정·기간 업무 화면과 업무실을 오가는 탐색, 권한 없는 메뉴 차단.

## 화면 근거와 한계

`screens/`의 이미지는 합성 학교·업무 자료를 넣은 **실제 구현 화면**이다. 운영 자료, 실제 교사 명부, 실제 시간표가 아니다. 개인 자료와 API 키는 포함하지 않는다.

320px·390px 및 데스크톱 너비, 큰 글자와 CSS 200% 확대를 자동 검사했다. 이 결과를 실제 휴대폰 키보드, 모든 기기의 Chrome 메뉴 200% 확대, 운영 Supabase 왕복 성공으로 확대 해석하지 않는다. 이번 UI 변경의 배포 후 확인은 사용자 미리보기와 Production 배포 이후에 진행한다.

DB·SQL·인증·권한·공개 레지스트리·서버 API·AI 비용·HWPX 엔진의 변경은 없다. 추가 SQL이나 서버 설정 없이 앱 PR만 배포한다.
