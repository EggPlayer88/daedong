프리텐다드와 기존 스킨 변수를 사용한다. 새 아이콘·폰트나 서버 API를 추가하지 않았다. SQL·DB·인증·비용·권한·메뉴 공개 범위는 변경하지 않았다.

## 판단해서 정한 것

1. **검색은 표시 목록만 좁힌다.** 선택한 수업이나 담당 교사가 검색 결과에서 빠져도 선택을 지우거나 다른 대상으로 바꾸지 않는다.
2. **입력 자체를 접지 않는다.** 접는 것은 관리 작업을 여는 버튼 묶음이다. 열린 편집기와 오류·충돌·결과 미상 복구는 기존 위치에 남긴다.
3. **학교 구성은 기존 전체 검토를 유지한다.** 항목 바로가기는 초점과 스크롤만 옮긴다. 학급·교과를 각각 자동 저장하지 않으며 기존 행을 삭제·재생성하지 않는다.
4. **불러온 기록 수를 전체 기록 수로 오인하지 않게 한다.** 관찰·평가 건수 앞에 ‘현재 불러온 기록’을 표시하고 이전 기록이 있으면 더 보기 안내를 붙인다. 상담은 이 집계에 넣거나 미리 조회하지 않는다.
5. **검색·접기·반응형 배치는 서버 권한을 대신하지 않는다.** 기존 기능별 조건과 명령을 유지하고, 관리 권한이 없는 응답에서는 접힌 곳에도 관리 버튼을 만들지 않는다.
6. **작은 화면에서는 배치만 바꾼다.** 입력 컴포넌트와 요청 번호를 다시 생성하지 않는다. 긴 이름·큰 글씨·어두운 스킨과 키보드 이동을 검증한다.

되돌릴 때는 이번 PR의 학교 관리·수업·편집기 TSX와 `school-records-ui.css`를 되돌린다. SQL이나 운영 데이터는 되돌릴 대상이 없다.

## 병합과 배포

추가 SQL이나 환경변수는 필요 없다. PR 최신 자동 검사와 Vercel 미리보기를 확인한 뒤 사용자가 `main`으로 merge commit한다. 이어서 Production이 해당 병합 커밋으로 Ready인지 확인한다.

미리보기에서는 학교 구성 검색 → 입력 바로가기 → 전체 변경 비교, 수업·학생 선택 → 관찰/평가 입력, 관리 도구 펼치기 → 자료 정정 영향 비교를 확인한다. 실제 교사 연결과 운영 자료를 변경하는 시험은 별도로 진행한다.
