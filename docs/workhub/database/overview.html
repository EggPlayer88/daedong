전체 구조

    학교 간 분리

    다른 학교의 유효한 자료 ID를 넣어도 연결되지 않도록 학교 ID를 관계와 권한에 함께 묶습니다.

    개인 자료 보호

    학교 관리 권한으로 타인의 관찰·상담·대화·미제출 초안을 자동 열람하지 못합니다.

    정정 가능한 연결

    근거가 바뀌면 연결된 결과를 재검토 대상으로 표시합니다. 과거 제출판이나 문장을 조용히 덮어쓰지 않습니다.

    구축 순서

    1. R0 · 기존 회원으로 실제 저장계정 보존 → 학교·소속·권한 → 일정·내 업무 연결과 재시도 검증
    2. R1 · 학교 업무를 하나로기본 파일·실행 기록 → 업무분장·공식 일정 → 수합 → 알림·인계
    3. R2 · 수업과 학생의 사실 기록명부·수강·담당 → 관찰·상담 → 디지털윤리 수업 앱 활동 연결
    4. R3 · 문서와 Claude검증된 지식·문서팩 → 상담·개인 비서 → 평가·생기부 초안과 문장별 근거

    학년도·학기·교과·학급·수업 기준표는 R1 업무·수합에 앞서 구축합니다. 시간표는 보류하며, 학교와 독립한 순수 개인 공간은 별도 후속 단계입니다.

    전체 DB 설계서SQL 구축 인계서기능·DB 연결표

    개념 연결도입니다. 모든 외래키를 표시한 물리 ERD는 아니며, 정확한 열·관계·상태·권한은 분야별 상세 설계가 기준입니다. 이 파일은 서버에 접속하지 않습니다.
