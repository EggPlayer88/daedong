## CI 실패 수정

PR #83 첫 CI는 단위 시험을 통과한 뒤 T3의 선행 T2 회귀에서 멈췄다. 실시 기록 시험이 29일 조회 범위의 수업 시각을 과거로 옮겼는데, 합반·휴업 시험이 16~36일 구간을 다시 사용해 실제 휴업 전에 차단되었다. `status`가 없는 미리보기 응답을 접수증처럼 읽어 원인이 가려지는 문제도 있었다.

기존 SQL과 판정 기준은 유지하고, 합반·휴업 시험 자료는 별도 36~56일 구간에 공개한다. 뒤의 T3 합성 수업도 70일 이후로 분리했다. 수정 전 실패를 로컬에서 재현했고, 수정 후 T2 114건·T3 79건과 실제 SQL 응답의 앱 parser 대조 75건이 통과했다. 이 수치는 격리 합성 자료의 자동 회귀이며 운영 기능 시험과 다르다. 최신 커밋의 전체 CI 결과는 별도로 확인한다.

검토/실행 SQL 8개의 UTF-8·LF SHA-256 목록은 `database/workhub-participation/op1/sql-package.json`에 있다. `package.py`는 실제 파일과 목록을 대조하며, CI에서도 점검 파일 재생성 후 대조한다. 설치문은 약 97kB, INT-10은 약 613kB다.
