## 남은 운영 반영

1. **앱 병합/배포:** PR #83 최신 CI 통과 뒤 merge commit으로 main에 반영하고, 같은 병합 커밋의 Vercel Production 성공을 확인한다. main 직접 push·강제 push는 하지 않는다.
2. **지정 교사 참여 허용:** OP1-03에 기존 시험 계정만 명시한다. 학교/소속/관리자 ID는 운영 조회로 확인했다. 현재 판은 0이고, 업무 범위·종료 시각·실제 배포 근거를 확인한 후 허용한다. 일반 교사 전체 공개는 하지 않는다.
3. **시간표 독립 승인 담당:** 현재 적격 담당자는 관리자 1명이다. 기존 시험 교사는 일반 교사로 유지한다. 다른 실제 교사 연결은 보류했으므로 별도의 승인 담당 계정과 역할을 결정해야 한다. 이 조건을 채우기 전 OP1-05/T3를 켜거나 2명 조건·자기 승인 차단을 우회하지 않는다.
4. **수업 관계:** 시험 교사의 실제 담당 수업과 학생 수강 관계는 별도로 지정해야 한다. 참여 범위를 부여했다고 기존 관리자 수업의 담당자를 일괄 바꾸지 않는다. 실제 학교 자료는 입력하지 않는다.

병합은 저장소 규칙상 사용자 작업이다. 대리 병합을 명시적으로 요청받으면 해당 커밋의 필수 검사를 확인한 뒤 진행한다. 새 업무 접근 허용·승인 역할 부여는 대상/범위/기간을 확인한 뒤에만 실행한다.
