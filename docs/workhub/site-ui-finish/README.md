## 판단해서 정한 것

1. 업무실 바깥의 기존 업무는 밝은 공통 스타일로 맞췄다. 업무실 Shadow DOM 내부의 밝음·어두움·따뜻함 스킨과 글씨·밀도 설정은 그대로다. 스타일을 되돌리려면 `apps/main/src/styles.css`의 전체 화면 마감 영역과 루트 색을 되돌린다.
2. 대시보드 바로가기는 `visibleModules`를 재사용한다. 라우트·메뉴 판정 표에 새 공개 조건을 넣지 않는다. 바로가기 배치를 바꾸려면 `DashboardPage.jsx`만 수정한다.
3. 화면 안 바로가기는 페이지를 교체하지 않고 현재 제목이나 입력으로 초점·스크롤만 옮긴다. `PageFrame.jsx`의 공통 컴포넌트를 사용한다. 화면 간 입력 보관은 이미 구현된 모듈의 보관·이동 잠금 규칙을 따른다. 모든 화면의 미저장 입력이 페이지 이탈 후 복구된다고 약속하지 않는다.
4. 긴 표를 카드로 바꾸거나 자료를 생략하지 않는다. 비교할 열과 이력을 유지하면서 표 안에서 스크롤한다. 모바일의 표 조작 방법도 함께 안내한다.
5. 긴 대화 목록 제목은 두 줄로 줄이고 전체 제목은 버튼 도움말과 선택한 대화 본문에서 확인한다. 답변 본문은 줄이지 않는다.

## 유지한 범위

- 기존 DB·SQL·RLS·인증·권한·공개 범위·기능 계약 변경 없음.
- AI 모델·단가·예산·명시 요청·같은 요청 번호 복구 변경 없음.
- 파일 생성 엔진·양식·검사·제출·취소 확인·다운로드 경로 변경 없음.
- 로그인 전후의 Google/별도 이메일 주소·승인 대기·일반 교사 경계 유지.
- 프리텐다드와 토스페이스는 기존 로컬 자산 재사용. 외부 폰트 서비스 추가 없음.
- 운영 DB·실제 회원·외부 설정·운영 메시지·유료 AI 호출은 이 작업에서 사용하지 않음.
