# 12차 UI·UX 개선 — 차분한 업무 화면과 개인 스킨

작성일: 2026-10-13  
브랜치: `feat/workhub-calm-ui`  
기준: `feat/workhub-calendar-import` · PR #18

## 교사가 보는 변화

기존 합성 미리보기와 신축 연결 화면의 표현을 바꿨다. 메뉴 구성·URL·공개 범위·업무 원본·저장 계약은 그대로다.

- 기본 스킨: 흰색 바탕, 차콜 본문, 차분한 파란 강조.
- 글꼴: 공식 Pretendard Variable 1.3.9를 자체 제공한다. 외부 글꼴 CDN은 호출하지 않는다.
- 공통 화면: 한자 로고·소개 문장·장식 강조를 줄이고 선 아이콘, 일정한 버튼, 얇은 구분선을 사용한다.
- 홈: 왼쪽은 내 할 일과 수합, 오른쪽은 오늘 및 다가오는 7일 일정이다. 좁은 화면은 한 열로 이어진다.
- 홈 요약: 개인 업무의 ‘나만 보기’, 기한 건수, 수합 역할, 보완 경고와 원본 이동을 유지한다. 빈 장소·반복 버전 표시·긴 사용 설명은 홈에서 줄이고 상세/펼침 영역에서 확인한다.
- 전체 화면: 일정·내 업무·수합·학생·검색·가져오기·모달의 입력, 상태, 색상, 글자 크기를 같은 스킨에 연결한다.
- 모바일: 기존 더보기 메뉴와 편집 중 이동 보호를 유지한다. 현재 화면은 제목과 선택된 메뉴로 알 수 있다.

## 화면 설정

사이드 메뉴의 **화면 설정**에서 즉시 바꿀 수 있다.

| 설정 | 값 | 기본 |
|---|---|---|
| 색상 | 화이트 / 웜 페이퍼 / 차콜 | 화이트 |
| 정보 간격 | 여유롭게 / 촘촘하게 | 여유롭게 |
| 글자 크기 | 기본 / 크게 | 기본 |

선택값은 `workhub:appearance:v1` 키에 세 필드만 저장한다. 업무 자료·회원 ID·학생 정보는 포함하지 않는다. 서버 저장이나 기기 간 동기화는 없다. 같은 브라우저의 다른 학교에서도 같은 화면 설정을 사용하며, 이미 열린 다른 탭의 즉시 동기화는 하지 않는다.

손상된 JSON·허용하지 않은 값·저장소 차단은 기본값과 명확한 안내로 처리한다. 저장 실패에도 현재 화면 설정은 바꿀 수 있다. ‘기본 설정으로’는 화면 설정만 복원하고 업무 자료를 건드리지 않는다. Escape·완료·닫기 후 시작 버튼으로 초점을 돌려준다.

구현:
- `appearance/preferences.ts`: 값 검증·브라우저 저장·React 훅.
- `appearance/AppearancePanel.tsx`, `appearance.css`: 설정 창·키보드/초점.
- `app/workspace-shell.css`: 스킨 토큰·공통 셸·홈 배치.
- `appearance/theme.css`: 기존 기능의 색상·글자·입력·상태 연결.
- 스킨 값을 늘리려면 허용값·선택 UI·토큰을 함께 갱신한다. CSS를 임의 업로드하는 방식은 제공하지 않는다.

## AI 비서 진입점

별도 메뉴/라우트를 추가하지 않고 공통 도구 영역에 작은 버튼을 뒀다. 누르면 Claude 연결 준비 상태와 기존 오늘·내 업무·학교 일정으로 가는 버튼을 보여준다.

**이번에 Claude 대화, 규정 상담, 업무 실행, API 호출을 구현한 것은 아니다.** 입력창·가짜 응답·전송 기능은 없으며 ‘준비 중’과 사용 불가 범위를 명시한다. 편집 잠금 중에는 이동 버튼을 사용할 수 없다. 향후 Claude 연결 시에도 학교 자료 상담과 개인 비서의 권한·실행 확인은 별도 계약에 따라 구현해야 한다.

## 글꼴·독립 미리보기

- 원본 WOFF2: 2,057,688 bytes. 첫 방문에 내려받고 브라우저 캐시를 사용한다. 이는 글꼴 다운로드 크기이며 화면 응답 시간을 측정한 수치는 아니다.
- 공식 출처·버전·SHA-256과 OFL 원문은 `assets/fonts/README.md`와 라이선스 파일에 남겼다.
- 글꼴 정의만 workhub와 기존 앱의 WorkhubPage 진입점에 불러온다. 글꼴 선택은 신축 셸에 한정한다.
- ShadowRoot 연결 화면에서도 전역 글꼴을 사용한다.
- exporter는 폰트를 내장하고 글꼴 data URI만 허용한다. 네트워크 연결 차단은 유지한다.
- OFL 원문은 소스·보존 CSS 주석·화면 하단 접힌 라이선스에 포함한다.
- 단일 HTML은 약 3.4 MB이다. 파일을 복사해 브라우저로 열 수 있으며 합성 자료만 사용한다.

- 레이아웃·표시 문구가 의도적으로 바뀐 기존 테스트만 갱신했다. 저장·권한·보완 의무·공개 범위 검사는 유지했다.

검사는 합성 자료와 연결 모의 환경에 대한 것이다. 실제 교사 사용성 평가, 실계정 운영 왕복, 전체 접근성 적합성 인증을 완료했다는 뜻은 아니다.

## 판단해서 정한 것과 조정 위치

1. 첫 화면은 업무·일정 두 흐름으로 구성했다. 메뉴를 유지하면서 시선 이동과 장식을 줄이기 위함이다. 조정 위치: CalendarPanel 홈 JSX, workspace-shell.css.
2. 3가지 스킨과 간격·글자 크기만 제공한다. 우선 선택이 쉽고 검증 가능한 범위를 만든 것이다. 조정 위치: appearance 디렉터리.
3. 한글 글꼴을 자체 제공한다. 외부 CDN 없이 독립 미리보기와 운영 화면의 모양을 맞추기 위함이다. 조정 위치: typography.css와 진입점 import.
4. AI 비서는 준비 상태를 공개하고 기존 기능으로 연결한다. 향후 접근 위치를 검토할 수 있게 하면서 실행 가능성을 과장하지 않기 위함이다. 조정 위치: WorkspaceAssistant.tsx와 셸 도구 영역.
5. 상세한 계약 안내는 접거나 원본에서 확인하게 했다. 개인정보 범위와 실패·보완 경고는 유지한다. 조정 위치: TaskPanel·HomeWorkSummary·CalendarPanel.
