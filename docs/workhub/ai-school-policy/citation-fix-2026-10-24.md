# 학교 자료 AI 인용 보완과 재시험 순서

2026-10-24 · PR #79 `fix/collection-download` 후속. 학교 자료 게시·원문 다운로드 시험에서 확인한 두 오류를 함께 보완한다.

## 문제와 수정

| 문제 | 원인 | 수정 |
|---|---|---|
| 2판 자료를 선택했는데 답변은 판 정보를 알 수 없다고 함 | SQL의 근거에는 `reference.version`이 있지만 공급자 입력에서 `reference`를 빠뜨림 | 확인한 근거의 `reference`를 그대로 전달. 자료의 판·파일 이름의 판·학년도를 구분하도록 명시 |
| 두 문장 사이에 줄바꿈 대신 `\n`이 표시됨 | 모델이 JSON 문자열의 줄바꿈을 이중 이스케이프함 | 원문 줄바꿈을 보존하도록 지시. 인용한 자료와 따옴표 안 전체 문장이 정확히 일치하는 경우에만 이중 이스케이프를 복원 |

학생 근거처럼 `reference.version`이 없는 종류에는 판 번호를 새로 붙이지 않는다. 답변의 인용 카드도 같은 서버 `reference`를 사용한다. `reference`는 근거를 식별하는 메타데이터이며 자료 본문의 지시문을 실행할 권한을 주지 않는다.

줄바꿈 복원은 큰따옴표·곡선 큰따옴표·겹낫표/낫표로 감싼 인용에 한정한다. 해당 답변 문단에서 실제로 인용한 자료만 대조한다. 원문에 역슬래시+n 자체가 있거나, 코드용 백틱이 섞였거나, 문장이 다르면 그대로 보존한다. 임의 `unicode_escape` 디코딩이나 모든 답변의 일괄 치환은 하지 않는다. 원래 길이·제어문자 검증을 먼저 통과해야 한다.

Haiku와 Sonnet은 같은 근거 입력·출력 검증 경로를 사용한다. 토큰 사전 계수와 생성에는 동일한 보완된 입력을 쓰며, 정산과 원번호 복구에는 복원된 답변을 저장한다. 추가 모델 호출은 없다. 기존에 저장된 대화나 자료 원문을 소급 수정하지 않는다.

- 수정 전 `7c89637`의 서버 코드를 메모리에 불러 같은 시험을 실행하면 **36 통과 / 4 실패**로 판 누락과 줄바꿈 오류가 재현된다. 작업 파일은 되돌리지 않았다.
- 관련 브라우저 **62/0**: 비서 27, 학교 자료·인용 20, 학교 AI 정책 15. 실제 React·어댑터·CSS를 사용하고 서버/공급자 응답은 합성이다. 새 시험은 파일 이름 v1/자료판 2 구분, 실제 줄바꿈과 경로 문자 보존, 같은 번호 복구·생성 1회를 확인한다.
- main·workhub 빌드와 업무실 타입 검사 통과.
- 전체 `npm test`: **5,131/0**, Python 생략 없음. 최초 묶음 실행에서는 이번에 변경하지 않은 CP-SAT 시험 한 파일이 실패했다. 시험이나 기대값을 바꾸지 않고 단독 29건과 전체 재실행을 모두 통과했다. 두 실행 결과를 합산하지 않는다.

## 배포와 재시험

1. **PR #79 최신 커밋**의 필수 test와 Vercel Preview가 통과하면 사용자가 **Create a merge commit**으로 병합한다. Codex는 병합하지 않는다.
2. Vercel **Production Ready**와 Source 커밋이 그 병합 커밋인지 확인한다. 이번 AI 보완 때문에 SQL·키·예산·환경변수를 다시 설정할 필요는 없다. 앞서 적용한 S1/S2/S3도 재실행하지 않는다.
3. 이미 게시한 `[연결시험] 학교 자료 HWPX 가져오기 · 2026-10-24` **2판**을 열어 **이 자료로 질문**을 누른다. 이전 답변 조회는 재시험이 아니므로 새 질문을 명시적으로 보낸다.
4. 아래 질문으로 Haiku 기본 답변을 한 번 확인한다. 판 확인 → 원문 인용 → 인용 원문 열기 → 운영 현황 정산 순서로 확인한다. Sonnet 자동 승격은 하지 않는다.

> 선택한 학교 자료 2판만 근거로 답해 주세요. 자료에 적힌 교사 표기는 무엇인가요? 마지막 문단의 두 문장을 원문 그대로 줄바꿈을 유지해 인용하고, 자료 제목·판·원문 위치를 출처로 적어 주세요. 제출 마감일이나 실제 학교 규정이 없다면 확인할 수 없다고 답해 주세요.

통과 기준:

- 교사 표기는 **가상교사**이며, 출처는 해당 자료 **2판**으로 표시된다. 판을 알 수 없다고 답하거나 파일 이름의 판으로 바꾸지 않는다.
- 인용의 두 문장 사이가 실제 줄바꿈이며 `\n` 두 글자가 보이지 않는다.
- **인용 원문 보기**가 같은 자료의 **2판**을 열고, 문장·줄바꿈이 일치한다.
- 원문에 없는 마감일·규정을 만들지 않는다. 요청은 완료, 사용량 정산 완료, 처리 중 예약은 0이다.

## 그다음: 개인 AI 기억

위 두 오류의 운영 재시험이 통과한 뒤 진행한다. M1은 이미 설치했으므로 `M1-01`을 다시 설치하지 않는다. 먼저 `M1-02`와 현재 학교의 준비 상태를 읽고, 사용자가 `M1-03_개인기억_학교승인_양식.sql`의 **관리자 소속 ID**·승인 근거·`true`를 확인해 실행한다. 회원 auth ID와 소속 ID를 혼동하지 않는다.

이후 가상 업무 선호 1개 저장 → 다시 조회 → 선택한 기억을 질문에 복사 → 수정/중지/삭제를 확인한다. 기억 선택만으로 AI를 호출하지 않으며, 저장한 기억을 모든 대화에 자동 주입하는 기능은 아니다. 실제 회원 연결·사용성 개편·Claude 최종 검토는 계속 별도 작업으로 둔다.
