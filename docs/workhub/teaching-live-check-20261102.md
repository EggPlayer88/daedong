## 발견한 문제와 수정

1. 일반 저장 중에도 pending 요청이 존재한다는 이유만으로 ‘이전 저장 결과를 먼저 확인해 주세요’와 복구 버튼이 나타났다. 통신 중에는 별도 처리 상태를 표시하고, 실패 후 결과가 미확정일 때만 기존 같은 번호 복구 안내를 표시한다. 기존 명령·요청 번호·중복 전송 잠금은 그대로다.
2. 개정 전 기준판을 조회하는 동안 ‘기준판을 확인할 수 없다’는 오류가 먼저 표시됐다. 대상별 조회 실패 상태를 구분해 응답 대기 중에는 조회 안내를 표시한다. 실제 조회 실패 시 기존 오류·저장 차단·입력 보존·취소는 유지한다. 다른 기준판으로 덮어쓰지 않는다.
