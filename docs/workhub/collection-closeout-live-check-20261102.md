## 발견한 결함과 앱 수정

### 1. 마감 후 보완 제출이 화면에서 막힘

기존 `P7-05_R1_P2_보강_별도승인.sql`의 `p7_phase_gate`는 마감 상태에서도 해당 제출 단위에 미완료 보완 요청이 있고 그 기한이 학교 오늘 이후(오늘 포함)라면 초안·파일 저장을 허용한다. 최종 제출은 해당 보완 요청 ID를 지정해야 한다. 그런데 앱은 마감 상태라는 이유만으로 모든 작성·첨부·저장·제출을 막았다.

`useCollectionEditor`와 `CollectionEditorView`를 단위별 보완 기한에 맞췄다. 기한 만료·이미 응답 완료·다른 단위·보관 상태에는 예외를 허용하지 않는다. 작성 중 요청이 끝나면 입력을 보존하면서 새 저장·업로드를 막는다. 마감 뒤 철회·정정 기간 설정, 보관 뒤 검토도 기존 서버 차단 규칙과 같은 안내로 맞췄다. 서버 판정이 최종이며 새 SQL이나 권한 확대는 없다. 이미 보낸 요청의 같은 번호 복구는 새 명령 차단과 분리해 유지한다.

### 2. 수합 운영 변경 중 안내 누락

마감·재개 등 명령 처리 중에 비활성 ‘원래 운영 요청 결과 확인’ 버튼만 나타났다. 이제 정상 처리 중에는 상태를 읽어 주고, 결과 미확정으로 끝났을 때만 복구 버튼을 표시한다. 입력·기존 명령·요청 번호와 중복 전송 잠금은 유지한다.
