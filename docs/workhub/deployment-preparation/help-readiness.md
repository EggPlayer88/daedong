## 안내에 연결한 흐름

- 학교 학급·교과 등의 일괄 입력 → 현재 구성 비교 → 초안 반영 → 확인 저장.
- 시간표 학기·공간·시수 → 조건·생성 후보 → 서버 초안 → 별도 확정, 그리고 교환·대강·휴강·보강.
- 담당자 양식 추천·질문/빈칸 연결 → 시험 파일 확인 → 게시.
- 교사 답변 저장 → HWPX 생성·직접 확인 → 수합 첨부 → 최종 제출 → 담당자 ZIP·현황표.
- 학교 자료의 현재 판·과거 원문 조회. 과거 판을 최신 AI 근거로 바꾸어 전달하지 않음.
- 기본 AI 답변·명시 정밀 검토, 개인 기억의 저장·선택·중지·삭제, 가상 교사 연습.

## 점검 범위

모든 항목은 기존 화면의 서버 어댑터와 응답 검증기를 사용한다. 명시된 조회 RPC만 한 번 호출하며, 학교·계정·소속이 바뀌거나 취소·시간초과가 발생하면 늦은 응답을 폐기한다. 조회 전에 사용자가 버튼을 눌러야 한다.

조회 응답 확인은 설치·쓰기·파일·AI까지 사용 가능하다는 뜻이 아니다. 준비가 일부 부족한 경우는 ‘확인 필요’에 남고, 중단되어 조회하지 않은 나머지는 ‘미확인’으로 남는다. 개인 AI 기억의 목록은 읽히더라도 쓰기 모듈이 중지되어 있으면 ‘이용 중지’로 표시한다.

전체 요약은 17개의 조회 항목 기준이다. 시스템 완성률이나 운영 활성화 비율로 환산하지 않는다. AI 예산·키의 서버 진단은 기존 학교 AI 이용 설정에서 별도로 확인한다. 이 도움말은 저장·메시지 읽음 처리·파일 전송·유료 AI 요청을 실행하지 않는다.

지원 JSON에는 `{id, code, checkedAt}`만 담는다. 이름·학교/회원 ID·학생 기록·문서 본문·기억 내용을 포함하지 않는다. 메뉴 이동이 거절되면 결과와 필터를 유지한다.
