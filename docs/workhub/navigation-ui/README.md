# 공통 메뉴·검색·알림·모바일 이동과 상태 안내

기준 main: `7e34dbe` (#92 병합). 작업 브랜치: `feat/workhub-navigation-ui`.

## 교사가 보는 변화

| 화면 | 이번 변경 |
|---|---|
| 공통 메뉴 | 상단에 업무 묶음과 현재 화면을 표시. 더보기에서는 현재 위치와 선택된 메뉴를 함께 표시 |
| 모바일 이동 | 기존 하단 메뉴·더보기 유지. 관련 업무 버튼은 좁은 화면에서 줄바꿈하고 버튼 높이 확보 |
| 업무 찾기 | 기존 프리텐다드·공통 스킨 적용. 자료 종류·제목·판·설명·원본 열기를 한 카드로 정리 |
| 검색 실패·빈 결과 | 불러오는 중/조회 확인 필요/일치 없음 구분. 조회 범위와 재조회 버튼은 계속 표시 |
| 업무 알림 | 읽음 상태·출처 업무·시각을 윗줄에, 제목·내용·읽음/원본 버튼을 아래에 배치. 미읽음은 색과 문구를 함께 표시 |
| 빈 대화·알림 | 필터를 확인하거나 대화를 선택하는 방법을 짧게 안내 |
| 연결 실패·복구 | 보관 입력과 결과 미상 요청의 상태를 제목으로 구분. 탭을 닫을 때의 손실 안내와 원래 복구/폐기 확인 유지 |
| 연결 점검 | 단계별 확인 결과와 다음 행동을 구분. 좁은 화면에서도 상태 문구를 별도 줄로 표시 |

## 유지한 범위

- 메뉴 목록·공개 범위·접근 검사·DB·SQL·RPC·API 변경 없음.
- AI 모델·단가·예산·호출·키·파일 생성/검사/다운로드 방식 변경 없음.
- 알림 보기와 원본 이동은 자동 읽음·승인·완료·제출을 하지 않는다. 기존 읽음 버튼만 해당 알림의 ID와 판을 보낸다.
- 검색의 범위별 조회·페이지·부분 결과·재시도·학교 전환 시 결과 폐기 로직 유지.
- 이동 잠금·초점 복원·입력 보존·같은 요청 번호 복구 유지. 모든 잠금 상황에서 영구 저장을 약속하는 표현은 사용하지 않는다.
- 프리텐다드·토스페이스는 기존 자산을 그대로 사용. 새 외부 폰트/아이콘 요청 없음.

## 판단해서 정한 것

1. 검색 실패와 결과 미상 요청은 접지 않는다. 빈 결과와 연결 실패를 구별한다.
2. 알림 제목보다 읽음·출처·시각을 작은 메타 정보로 먼저 구분한다. 원본 열기와 읽음 표시는 별개 행동으로 유지한다.
3. 메뉴를 추가하지 않고 현재 위치와 관련 업무를 표시한다. 일반 교사 참여 화면도 전달된 허용 메뉴만 표시한다.
