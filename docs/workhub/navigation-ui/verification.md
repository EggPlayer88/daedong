## 주요 회귀

- 실제 메뉴·일반 교사 참여 범위, 모바일 하단 메뉴/더보기, 키보드 닫기/초점 복원, 본문 건너뛰기.
- 검색 ID·원문 판·부분 조회·실패 재시도·학교 변경 후 늦은 응답 폐기·검색어 보존.
- 알림 조회/원본 열기와 읽음 분리, 원본 접근 불가, 본문 줄바꿈, 기존 메시지·HWPX 파일 복구.
- 결과 미상 요청과 작성 중 입력 보존, 같은 번호 재전송, 모듈 오류 격리, 연결 오류에서 입력 폐기 확인.
- 320px, 두 배 글씨, 밝게/따뜻하게/어둡게 스킨의 주요 텍스트 대비(4.5:1 이상), 대화상자 가로 넘침.

## 시험 수정

기존 `test_workhub_shell.mjs`의 잠금 안내 검사는 본문 앞의 제목 요소를 허용하지 않는 정규식이었다. 제목·기존 안내 본문 전체를 함께 대조하도록 수정했다. 이동 버튼 disabled/aria-describedby와 더보기 탐색 가능 검사는 그대로 둔다.

## 실행 경계
