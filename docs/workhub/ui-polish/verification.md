## 범위와 실제 운영의 구분

실제 React·전송 어댑터·응답 parser·로컬 계산기를 사용했다. 학교·교사·DB/Storage/AI 응답은 합성 자료이며 운영 DB·실제 회원·유료 AI를 변경하거나 호출하지 않았다. 캡처는 콘셉트 그림이 아닌 이 시험 화면이다.

SQL, 서버 API, 인증, 메뉴 공개 설정과 모델/예산 파일의 변경이 없다. DB 활성화나 추가 SQL 실행이 필요하지 않다. GitHub CI와 Vercel 미리보기 상태는 PR의 최신 커밋에서 별도로 확인한다. 운영 적용은 사용자 병합과 Production 배포 뒤 확인한다.
