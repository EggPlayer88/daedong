## 우선순위가 높은 남은 작업

1. **서버 연결 묶음:** 준비한 P9 → P10 → T3 → T4와 읽기 전용 점검의 적용 준비를 마무리하고 사용자가 적용한다. 이미 적용한 이전 SQL을 재실행하지 않는다. 이번 작업에서는 적용하지 않았다.
2. **실제 학교 자료 묶음:** 가입 교사 연결, 두 번째 승인 담당자, 학기·학급·교과·수업·공간·시수·학생·공식 시간표를 현재 일괄 입력 화면으로 연결한다. 자료와 담당을 추정해서 넣지 않는다.
3. **문서·메신저 연결 묶음:** 운영 Vercel의 HWPX 검사 엔드포인트와 서버 전용 설정, Storage 접근을 연결한 뒤 관련 정책을 켠다. 독립 검사기 서버·자동 정리는 이번 범위에 다시 넣지 않는다.
4. **AI 비용 결정 뒤 구현 묶음:** C7 사전 토큰 계산·예약/정산/해제·실패 상태의 앱/서버/SQL을 확정해 연결한다. 기존 호출 구조가 있다고 비용 정책 보강까지 완료된 것으로 계산하지 않는다.
5. **원래 전체 청사진의 추가 구축:** 전체 메뉴 검색, 지식 과거 원문판 조회, 장기 AI 기억, 자동 양식 추천·질문 매핑, 외부 수업 API 연동. 이번에 마친 지식 원문 왕복과 문서 저장판 비교·인쇄는 여기서 제외했다. 장기 기억과 외부 연동은 새 데이터·권한·보관 계약이 필요해 DB 적용을 기다리는 화면 기능만으로 완료할 수 없다.

이후의 실제 사용 점검과 피드백은 위 구축 목록과 별도로 진행한다. 모든 기능이 ‘99% 구축 완료’라고 선언할 수 있는 상태로 표현하지 않는다. 특히 비용 통제·자동 외부 연동·장기 기억은 설정만 남은 항목이 아니다.

## 사용자 결정이 필요한 항목

- 비서의 모델·단가·예산·보관기간·결과 미상 요청 확인 담당과 비용 구조 보강(C7).
- 실제 교사 명단·재직 기간·담당·학생 식별·공식 학교 자료.
- SQL 적용·모듈 활성화·일반 교사 공개 시점.

검증 숫자와 실행 범위는 [verification.md](verification.md)에 기록한다. 브라우저 자동 시험은 실제 React와 앱 전송 어댑터를 사용하며 DB·Storage·Claude 응답은 합성이다. 이를 실제 서비스 연결 성공으로 바꾸어 표시하지 않는다.
