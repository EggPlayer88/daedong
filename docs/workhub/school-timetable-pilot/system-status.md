## 우선순위가 높은 남은 작업

현재 지시대로 아래 실제 적용·회원 연결·Claude 검토는 마지막으로 보류한다. 운영 작업을 먼저 실행하라는 목록이 아니다.

1. **앱·계약 마무리 상태:** 개인 AI 기억, 수합 방식·질문/칸 연결 제안, 메뉴 검색·지식 과거판 조회, 사용 안내·연결 점검은 구현과 자동 시험을 마쳤다. 마지막 연결 단계에서 실제 서버 계약 차이가 드러나면 수정한다. 자동 기억 수집·전체 대화 주입·PDF 원문 추출·범용 복합 서식 편집처럼 새 계약이나 범위 결정이 필요한 기능을 이미 완성한 것으로 표시하지 않는다. 외부 수업 사이트 자동 연동은 이번 작업에서 제외한다.
2. **서버 연결 묶음:** 학교 자료 P9/P10·시간표 T3/T4·AI 정책 P10·과거 학교 자료 K1·개인 AI 기억 M1의 적용 목록·해시·사전/사후 점검·새 INT-05를 준비했다. 최종 검토 뒤 실제 운영 기준선과 설치 여부를 대조하고 승인된 순서로 적용하는 일은 남아 있다. AI P10은 설치만으로 이전 AI 호출에 영향을 주므로 앱·학교 키·학교 연결 전환을 함께 준비해야 한다. 이미 적용한 SQL은 재실행하지 않는다.
3. **문서·메신저·AI 연결:** 운영 Vercel의 HWPX 검사·학교 원문·질문형 문서 엔드포인트, 서버 전용 설정, Storage, 학교 키·공통 예산을 연결한다. 독립 검사기 서버·자동 정리는 이번 범위에 다시 넣지 않는다.
4. **마지막 실제 학교 전환:** 가상 자동 시험과 최종 Claude 검토 이후 승인된 기존 가입 교사·독립 승인 담당자·실제 학교 자료를 연결한다. 가상 교사의 동의나 제출을 실제 회원의 것으로 이관하지 않는다.

이후의 실제 사용 점검과 피드백은 위 구축 목록과 별도로 진행한다. 모든 기능이 ‘99% 구축 완료’라고 선언하지 않는다. 승인된 AI 비용 통제는 코드·SQL 준비를 마쳤지만 실제 적용은 남았고, 개인 AI 기억은 앱·M1 SQL 준비를 마쳤지만 실제 설치·학교 승인·서버 왕복은 남아 있다. 양식 제안은 구현됐지만 담당자의 원본 확인과 최종 저장이 필요하다.
