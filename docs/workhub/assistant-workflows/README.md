# 대화에서 업무로 연결

## 교사가 보는 변화

기존 AI 입력칸에서 메뉴를 열고, 현재 권한으로 자료를 찾고, 개인 할 일을 제안받아 확정할 수 있다. 일정은 날짜·시간을 채운 기존 편집기로 연결한다. 화면 버튼으로 하는 방식도 유지한다.

| 입력 예 | 처리 | 저장·비용 |
|---|---|---|
| 시간표 열어줘 | 기존 시간표 화면으로 이동 | AI 호출·저장 없음 |
| 학교 자료에서 출장 찾아줘 | 기존 학교 자료 검색 결과 표시, 선택한 원본·판 열기 | AI 호출 없음, 첫 쪽 조회 |
| 문서함에서 학교 행사 찾아줘 | 문서 결과와 정확한 판을 기존 문서함에 연결 | AI 호출 없음 |
| 제출 자료 확인을 할 일로 추가해줘 | 기존 개인 비서 요청 → 할 일 제안 → 내용 확인 → 개인 할 일 저장 | 기존 Haiku 1회, 기존 확인 RPC |
| 내일 오후 3시부터 4시까지 회의 일정 초안 만들어줘 | 학교 기준 날짜로 다음 날 15:00~16:00 초안 열기 | AI 호출 없음, 편집기에서 저장해야 반영 |

일정의 제목·날짜·시작/종료 시각이 빠지면 보완을 요청한다. 종일 일정은 ‘종일’을 명시한다. 여러 날짜·반복·공유 대상이 섞인 요청은 임의로 정하지 않는다. 지원 예시는 입력칸 아래 ‘대화로 할 수 있는 일’에서 펼쳐 볼 수 있다.

## 처리 경계

- 기존 AI 비서 진입 범위에만 연결한다. 일반 교사 공개나 참여 모듈 범위를 늘리지 않는다.
- 사용자가 직접 입력한 명시 요청만 로컬 분류한다. AI 답변·학교 자료 본문·개인 기억을 명령으로 실행하지 않는다.
- 다른 화면에서 선택한 학생·문서 근거가 붙은 요청은 기존 생성 흐름을 유지한다.
- 메뉴와 자료 조회는 유료 AI 준비 상태와 분리하지만, 기존 연결·검색·원본 서비스의 계정·학교·권한 검사는 유지한다.
- 조회는 기존 검색 loader를 사용한다. 첫 쪽의 결과 중 최대 20개를 보이며, 미조회·부분 실패·범위를 표시한다. 학교 자료 전체를 AI로 보내거나 자동 수집하지 않는다.
- 개인 할 일은 기존 AI 제안 ID와 판을 확인하고 사용자가 확정해야 저장한다. 결과 미상 시 원래 요청 번호·명령을 유지한다. 정밀 검토 자동 호출은 추가하지 않는다.
- 일정은 기본 ‘나만 보기’·본인 대상으로 열린다. 공유와 최종 저장은 기존 편집기에서 확인한다. 이미 작성/복구 중인 일정이나 미확정 저장을 덮어쓰지 않는다.
- 이동·검색 결과와 일정 전달은 현재 계정/학교에 묶인 탭 상태다. 브라우저 종료 후 복원이나 자유로운 다단계 자동 실행을 약속하지 않는다.
- 삭제·전송·제출·승인·공개를 대화에서 자동 실행하는 기능은 이번 범위가 아니다.

## 구조와 판단 근거

| 계층 | 파일 | 이유 |
|---|---|---|
| 사용자 문장 분류 | `assistant/workspace-commands.ts` | 이동·검색처럼 확실한 요청에 모델 비용을 추가하지 않는다. 파서는 실행 권한을 만들지 않는다. |
| 대화 처리와 결과 | `assistant/useAssistantWorkspace.ts`, `WorkspaceCommandResult.tsx` | 기존 요청 복구·할 일 확인을 재사용하고 별도 채팅 화면을 만들지 않는다. |
| 자료 조회 | `assistant/workspace-search.ts` | 기존 검색의 응답 검사와 범위를 그대로 사용한다. |
| 화면 연결 | `app/ConnectedWorkspace.tsx` | 기존 이동 잠금·원본 열기·학교 변경 정리를 통과한다. |
| 일정 초안 수신 | `calendar/assistant-draft.ts`, `CalendarPanel.tsx` | 학교/소속을 다시 대조하고 기존 편집기로 전달한다. 같은 전달 번호를 다시 소비하지 않는다. |

되돌리기는 이번 앱 변경을 되돌리는 PR로 처리한다. SQL 설치·환경변수 변경·모델/예산 설정 변경은 필요 없다. 이 변경으로 저장한 개인 할 일·일정은 기존 데이터 계약이므로 앱을 되돌려도 기존 화면에서 조회할 수 있다.

## 검증과 실제 서비스의 구분

신규 단위 시험은 문장 해석, 날짜·시각, 취소·부분 실패와 조회 한도, 일정 초안 범위를 다룬다. 신규 브라우저 시험은 실제 React, 기존 연결 어댑터·parser·편집기에 합성 응답을 넣어 이동/검색/확정/복구를 검증한다. 운영 DB 쓰기나 실제 유료 AI 요청은 시험하지 않았다.

상세 결과와 배포 기준은 [verification.md](verification.md)에 기록한다.

## 메시지와 자료 수합 초안

보낼 문구가 정해져 있으면 AI 옆자리에 “메시지 초안: 내일 회의 자료를 확인해 주세요”라고 입력한다. 메시지 화면에서 **전달받은 메시지 초안 사용**을 누르면 본문이 채워진다. 받는 사람과 첨부는 직접 선택하고 기존 미리보기에서 전송을 확인한다.

“수합 초안: 현장체험학습 계획서”는 자료 수합 화면으로 연결된다. 둘째 줄에 “안내: 학급별 계획을 적어 주세요”를 붙일 수 있다. **수합 초안 사용**을 누르면 원래 편집기에서 제목과 안내를 확인하고 제출 기한·대상·양식을 정할 수 있다. 초안 저장과 게시는 기존 버튼에서 각각 처리한다.

두 입력 형식은 모델 호출 없이 작성 화면에 원문을 전달한다. “학교 행사 안내 메시지를 짧게 작성해 주세요”처럼 글쓰기를 부탁하면 기존 AI 답변 경로를 사용한다. 작성 중인 내용이나 미확정 요청이 있으면 먼저 해당 화면에서 마무리한 뒤 이어서 진행한다.
