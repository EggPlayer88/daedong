## 남는 경계

- 시험 기간은 기존 OP1과 같은 최대 7일이다. 자동 연장하지 않는다.
- 시험 교사는 학교의 기존 참여 권한을 사용한다. 전체 교사 수신을 서버에서 시험 명단으로 강제 제한하지 않으므로 실제 시험에서는 대상 10명과 관리자만 직접 확인한다.
