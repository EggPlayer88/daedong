## 1. 비율 결정 권한 구조 (대원칙)

규정은 교과별 구체 수치를 직접 정하지 않는다. 수치는 아래 절차로 확정되며, 규정은 **한계선(상한·하한)과 절차 요건**만 정한다.

```
교과(학년)협의회 수립 → 학업성적관리위원회 심의 → 학교장 최종 결정 → 평가계획서 명시 → 학기 초 정보공시 공개
```

| 단계 | 근거 조문 |
|---|---|
| 평가계획 수립 주체 = 교과(학년)협의회 | 제10조 ①, 제11조 ①, 제19조 ② |
| 위원회 심의 대상 = 영역·요소·방법·시기·횟수·세부기준(배점·채점기준)·반영비율·성적처리방법 | 제7조 ② |
| 지필·수행의 시기·횟수·반영비율은 교과별 평가계획서에 명시 | 제11조 ② |
| 평가계획서 필수 포함 항목(영역·방법·시기·횟수·반영비율, 성취수준, 수행 세부기준, 결시·학변자 인정점 기준, 기본점수 여부 등) | 제10조 ③ |
| 확정 계획 학기 초 공개(정보공시 등), 변경 시 위원회 심의 후 사전 안내 | 제10조 ⑪ |

## 3. 유형별 한계선 매트릭스

| 유형 | 지필 횟수 | 지필 상한 | 수행 하한 | 서·논술형 | 심의 요건 | 근거 |
|---|---|---|---|---|---|---|
| A. 일반형 | 학기 2회 | ≤ 70% | ≥ 30% | 총 배점의 ≥30%, 지필 매회 포함 | 통상 심의(제7조 ②) | 제10조 ④⑤, 제19조 ⑦ |
| B. 지필 1회형 | 학기 1회 | **≤ 40%** | ≥ 60% | 동일 | **위원회 심의 + 학교장 결정 필수** | 제10조 ⑤ |
| C. 수행 100%형 | 0회 | 0% | 100% | 반영 여부·비율을 협의회가 정해 위원회 심의 | **위원회 심의 필수** | 제10조 ⑥ |
| D. 자유학기 | 정기고사 미실시 | 0% | 과정중심 100% | 해당 없음 (성취도 미산출) | 위원회 심의(제7조 ⑦) + 학교장 결정 | 제10조 ⑧, 제11조 ③, 제23조 |

- 유형 B 적용 가능 교과: (1) 도덕, 기술·가정 (2) 3학년 2학기에 편성된 교과 (3) 수행 100% 가능 교과 — 제10조 ⑤ (1)~(3)
- 유형 C 적용 가능 교과: (1) 정보, 선택 교과, 체육, 예술(음악·미술), 학교자율시간 과목 (2) 주당 1시수 편성 과목 — 제10조 ⑥ (1)~(2)
- ⑤·⑥은 모두 임의규정("할 수 있다")이므로, 해당 교과가 A 유형(일반형)을 선택하는 것도 가능함.

## 4. 교과별 상세 한계선

각 교과가 선택 가능한 유형과 그때의 한계선. 구체 % 확정은 교과협의회 소관(제11조).

### 4-1. 국어 / 수학 / 영어 / 사회(역사 포함) / 과학
- 허용 유형: **A(일반형)** 기본. 3학년 2학기에 한해 B 선택 가능(제10조 ⑤(2)).
- 한계선: 지필 ≤70%(2회 합산), 수행 ≥30%, 수행 영역당 ≤40%, 서·논술형 ≥30% + 지필 매회 포함.
- 영어 특례: 시도 공동 영어듣기평가는 수행평가로 활용 가능(제19조 ④ 단서).

### 4-2. 도덕
- 허용 유형: A 또는 **B(지필 1회)** — 제10조 ⑤(1) 명시 교과.
- B 선택 시: 지필 ≤40%, 수행 ≥60%, 위원회 심의 + 학교장 결정 필수. 처리 기준일 위원회 결정(제24조 ⑥).
- 학기 1회 지필 과목의 학적변동자 처리는 제18조 ⑭·제26조 연동 (전입생 중복/전무 케이스 주의).

### 4-3. 기술·가정
- 도덕과 동일: A 또는 B — 제10조 ⑤(1).
- B 선택 시 동일 한계선(지필 ≤40%, 수행 ≥60%) 및 동일 절차 요건.

### 4-4. 정보
- 허용 유형: A / B(⑤(3) 경유) / **C(수행 100%)** — 제10조 ⑥(1).
- C 선택 시: 위원회 심의 필수, 서·논술형 반영 여부·비율은 협의회 결정 → 위원회 심의. R5(논술형만 불가)·R3 계열 영역 규칙 적용.

### 4-5. 체육
- 허용 유형: A / B / **C(수행 100%)** — 제10조 ⑥(1).
- 성취도 A–C 산출(제10조 ②), 성적일람표는 성취도만 산출(제24조), 자유학기엔 'P'(제23조 ③).
- 영역당 40% 완화 단서 적용 대상(제19조 ⑦ ※).

### 4-6. 음악 / 미술 (예술 교과)
- 체육과 동일: A / B / C, 성취도 A–C, 영역당 40% 완화 단서 적용.

### 4-7. 선택 교과 (한문, 생활외국어, 교양 성격 과목 등)
- 허용 유형: A / B / **C** — 제10조 ⑥(1) "선택 교과".
- 고등학교 교양교과 성격 과목도 평가계획 수립 의무(제10조 ② ※).

### 4-8. 학교자율시간 과목
- 편성된 교과(군)의 평가방식을 따르되 평가 방법은 달리할 수 있고 이를 평가계획에 반영(제10조 ② ※).
- C(수행 100%) 선택 가능 — 제10조 ⑥(1). 평가 기준·방법은 위원회 별도 심의 사항(제7조 ⑧).

### 4-9. 주당 1시수 편성 과목 (교과 불문)
- C(수행 100%) 선택 가능 — 제10조 ⑥(2).
- 영역당 40% 완화 단서 적용 대상(제19조 ⑦ ※).

### 4-10. 학년·학기 축 특례
| 구분 | 내용 | 근거 |
|---|---|---|
| 1학년 자유학기 | 정기고사 미실시, 과정중심 수행 100%(활동지·형성평가·관찰 누적, 자기·상호평가 병행), 성취도 미산출, 원점수/과목평균 공란·성취도 'P', 교사별 평가계획 가능 | 제10조 ⑧, 제11조 ③, 제23조 |
| 3학년 2학기 | 전 편성 교과 지필 1회(유형 B) 선택 가능 → 지필 ≤40% | 제10조 ⑤(2) |
| 수행평가 교사별 평가 | 전 학년 허용 | 제19조 ② |

## 6. daedong-v2 검증 룰셋 (평가계획서 자동 검증용)

severity: `ERROR`(규정 위반) / `WARN`(확인 필요) / `FLAG`(위원회 심의 필요 표식)

```
V01 ERROR  수행 반영 합계 < 30                          → 제19조 ⑦ 위반
V02 ERROR  수행 단일 영역 > 40 AND 과목 ∉ {1시수, 음악, 미술, 체육} → 제19조 ⑦ 위반
V03 WARN   수행 단일 영역 > 40 AND 과목 ∈ {1시수, 음악, 미술, 체육} → 완화 단서 대상 확인(제19조 ⑦ ※)
V04 ERROR  서·논술형 환산 배점 < 총 배점의 30 AND 유형 ≠ C·D      → 제10조 ④ 위반
V05 ERROR  지필 회차 중 서·논술형 미포함 회차 존재               → 제10조 ④ 위반
V06 ERROR  지필 횟수 = 1 AND 지필 반영 > 40                    → 제10조 ⑤ 위반
V07 ERROR  지필 횟수 = 1 AND 과목 ∉ {도덕, 기술·가정} AND 학기 ≠ 3-2 AND 과목 ∉ 수행100%가능군 → 제10조 ⑤ 각 호 위반
V08 ERROR  수행 100% AND 과목 ∉ {정보, 선택, 체육, 음악, 미술, 학교자율시간, 1시수} → 제10조 ⑥ 위반
V09 FLAG   지필 횟수 = 1 OR 수행 100%                        → 위원회 심의·학교장 결정 필요(제10조 ⑤·⑥) + 기준일 별도 결정(제24조 ⑥)
V10 ERROR  수행 영역 전체가 논술형                            → 제19조 ⑤ 위반
V11 ERROR  기본점수 > 영역 배점의 40%                         → 제19조 ⑧ 위반
```

## 7. 시스템 반영 시 유의

1. 규정은 상한·하한만 정한다 — 생성 로직이 구체 %를 제안할 때는 "규정 적합 범위 내 예시"임을 UI에 명시할 것 (수치 확정 권한은 교과협의회, 제11조).
2. 유형 B·C는 임의규정이므로 해당 교과의 유형 선택지를 강제하지 말고 선택형으로 제공할 것.
3. V09 FLAG가 뜨는 과목은 위원회 심의 안건 목록으로 자동 집계하면 공문 기안(5장 근거 세트)과 바로 연결됨.
4. 서·논술형 30%는 "정기시험 내 30%"가 아니라 **학기말 총 배점(지필+수행 환산 합계) 기준**임 — 계산 분모 주의 (제10조 ④).
5. 규정 내 훈령 번호 불일치(555호 vs 504호)는 시스템 문제는 아니나 규정 개정 검토 목록에 등재 권장.
